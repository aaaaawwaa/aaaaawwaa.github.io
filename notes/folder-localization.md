# 目录中文显示名（folder localization）

## 问题与目标

网站内容目录使用英文小写 slug（URL 与磁盘路径必须稳定，避免大小写敏感部署下的 404），但读者看到的左侧目录树、目录页标题、面包屑和搜索结果是英文目录名（dsp、random-signals、5g…）。本机制在不改 URL、不动插件与构建产物的前提下，把这些**显示名**换成 Obsidian 源库里的中文目录名。

## 机制（为什么只加 index.md 就够）

Quartz 5 的目录显示名有三个来源，都优先读目录 index 页面：

| 位置 | 取值来源 | 依据 |
| --- | --- | --- |
| 左侧 Explorer | 运行时读 `static/contentIndex.json`，文件夹节点用 `<dir>/index` 条目的 title | explorer 插件的前端 trie：displayName = data.title |
| 目录列表 / 目录页标题 | folder-page 插件的 `pagesFromTrie` 用节点 displayName；有 index 的目录直接以 index 页为页面 | folder-page 插件 |
| 面包屑 | fileTrie 中文件夹节点的 data 即该目录 index 条目 | breadcrumbs 插件 resolveFrontmatterTitle |
| 搜索 | contentIndex 的 title 字段 | content-index 插件 |

因此给每个可见目录生成一个带中文 `title` 的 `index.md`，四处显示名同时生效，且 URL 不变（`/vault-notes/dsp/` 仍由 `vault-notes/dsp/index.md` 提供）。

## 维护方式

- 映射文件：仓库根目录 `folder-titles.json`。每个键是站内目录（`vault-notes/...`，与磁盘一致），值包含 `title`（中文显示名）、`source`（Obsidian 源目录名，便于核对）、`description`（目录页说明）。
- 生成器：`scripts/build-folder-indexes.mjs`
  - `npm run folders:build` 生成/更新各目录的 `index.md`；
  - `npm run folders:check` 只校验（`npm run verify` 与 CI 都会执行）。
- 生成页带 `<!-- folder-index: generated by scripts/build-folder-indexes.mjs -->` 标记。**没有标记的 index.md 视为人工页，生成器拒绝覆盖**；根目录 `vault-notes/index.md` 是人工维护的入口页（映射里标 `manual: true`，只校验标题）。
- 生成器的检查项：
  1. 所有公开可见目录（含自动推导出的父目录）都必须有映射，否则失败；
  2. 每个映射项的父目录也必须映射，避免面包屑残留英文；
  3. 映射项必须真实存在；人工页标题必须与映射一致；
  4. 生成页不能脱离映射继续存在；
  5. `--check` 模式下任何缺失或过期都会使构建失败。

## 新增目录时

1. 在 `public-notes.json` 增加该目录下的笔记（同步后出现新目录）；
2. 在 `folder-titles.json` 为**新目录及其父目录**补映射（`source` 写 Obsidian 源目录名）；
3. 运行 `npm run folders:build`，检查生成的 index.md 标题与入口；
4. `npm run verify` → 提交推送。

## 当前映射（2026-10-28）

28 个目录：根入口 + 12 个一级学科/主题目录 + 15 个二级及更深目录。要点：

- `vault-notes/math` 是网站聚合层（源库没有同名总目录，三科在源库各自独立），显示为「数学基础」，其下 linear-algebra / probability / complex-analysis 分别对应源目录「线性代数」「概率论与数理统计」「复变函数与场论」。
- `vault-notes/maps` 对应源目录「03-Maps」，显示为「知识地图」（语义名）。
- `5g/protocols` 在源库按 OSI 分层组织，显示名沿用「OSI分类」；`fpga/architecture` 与 `5g/architecture` 分别显示「FPGA结构」「5G核心架构与规范」，不共享同一中文名。
- `matlab` 显示为「Matlab」，与源目录大小写一致；品牌与技术缩写（5G、FPGA、AD9361、BASE、Vivado）保持原样。

## 已知边界

- 附件目录 `vault-notes/assets` 不含 Markdown，不参与内容索引，因此不会出现在目录树与目录列表里。
- 插件自带的系统文案（Explorer / Graph View / Table of Contents 等）属于另一个问题（CI 构建的插件 i18n 资源与本地预构建包不同），本轮不翻译品牌与技术缩写，也未改动插件。
- 目录改名只影响显示名，不改变已发布笔记的 slug；已有外链继续有效。
