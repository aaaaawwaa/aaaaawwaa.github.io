## 一张表怎么用：条件比公式更重要

通信原理的公式几乎都不是"无条件成立"的。同一条 $P_e$ 公式，换一种解调方式、换一个噪声带宽定义、换一组比较基准（同峰值还是同平均功率），结果就会差 3 dB 甚至更多。所以查表时要按三步走：

1. **先确认模型**：AWGN 还是随参衰落？相干还是非相干？等概还是非等概？
2. **再确认变量**：$r$ 是解调器输入信噪比，$E_b/N_0$ 是每比特能量噪声比，二者只有在特定噪声带宽定义下才相等；
3. **最后看单位**：$B$ 是双边带宽还是单边？$n_0$ 是单边谱密度还是双边谱密度？

下面按教材章节顺序汇总，关键处标注适用条件与常见错误。

## 数字通信系统的组成

一条完整的数字通信链路是：信源 → 输入变换器（模/数转换）→ 信源编码器（压缩去冗余）→ 信道编码器（加受控冗余）→ 数字调制器（基带搬上频带）→ 信道 → 数字解调器 → 信道译码器 → 信源译码器 → 输出变换器 → 信宿。

- **信源编码**：把模拟或数字信源的输出有效变换成二进制序列（信息序列），目标是提高有效性；
- **信道编码**：在信息序列中受控地增加冗余，使接收端能克服噪声与干扰，目标是提高可靠性。

这张图与教材绪论的"数字通信系统模型"一致，也是本分类各篇文章的组织顺序：信号与信道（第 2–4 章）→ 模拟与数字调制（第 5–8 章）→ 最佳接收（第 9 章）→ 编码与同步（第 10–13 章）。

## 绪论：信息量与性能指标

| 公式 | 含义 | 条件/易错 |
| --- | --- | --- |
| $I=\log_2\frac{1}{P(x)}$ | 消息信息量（bit） | 概率越小信息量越大；$P=1$ 时 $I=0$ |
| $I=\log_2M$ | $M$ 进制等概符号的信息量 | $M=2^k$ 时一码元含 $k$ bit |
| $H=-\sum_iP(x_i)\log_2P(x_i)$ | 信源熵（bit/符号） | 等概时最大，$H_{\max}=\log_2M$ |
| $R_b=R_B\log_2M$ | 信息速率与码元速率 | 只有二进制时二者数值相等 |
| $\eta=\frac{R_B}{B}$，$\eta_b=\frac{R_b}{B}$ | 频带利用率（Baud/Hz、bit/(s·Hz)） | 分母都是带宽 |
| $P_e$、$P_b$ | 误码率、误信率 | 二进制 $P_b=P_e$；多进制一般 $P_b<P_e$ |

这组量是全书的两把尺子：**有效性**看 $\eta$ 或占用带宽，**可靠性**看 $P_e$ 或输出信噪比。后面所有系统比较都是在两者之间做交换。

## 信号与噪声的数学语言

**能量信号与功率信号**：能量 $E=\int s^2(t)\,dt$ 有限者为能量信号；平均功率 $P=\lim\frac{1}{T}\int_{-T/2}^{T/2}s^2(t)\,dt$ 有限非零者为功率信号。周期信号、噪声是功率信号。

**频域**：能量信号用傅里叶变换，能量谱密度 $G(f)=|S(f)|^2$；功率信号先截断再取极限，功率谱密度 $P(f)=\lim\frac{1}{T}|S_T(f)|^2$。**帕塞瓦尔定理**保证时域与频域能量一致。

**相关与谱**：$R(\tau)$ 与 $P(f)$ 互为傅里叶变换（**维纳–辛钦定理**），$R(0)$ 是总平均功率。

**噪声模型**：白噪声双边谱 $n_0/2$、自相关 $\frac{n_0}{2}\delta(\tau)$；经带宽 $B$ 的带通滤波器后 $\sigma_n^2=n_0B$（用单边谱）。平稳过程通过线性系统 $P_o(\omega)=|H(\omega)|^2P_i(\omega)$。窄带高斯噪声的包络服从瑞利分布，正弦信号加窄带噪声的合成包络服从莱斯分布；**只有噪声时瑞利，信号强时近似高斯**。

**误差函数**：$Q(x)=\frac{1}{2}\mathrm{erfc}\left(\frac{x}{\sqrt{2}}\right)$。相干解调的误码率写成 $\frac{1}{2}\mathrm{erfc}(\sqrt{\cdot})$，非相干写成 $e^{-\cdot}$。

**信道**：调制信道 $e_o(t)=k(t)e_i(t)+n(t)$，$k(t)$ 恒定/缓变为恒参信道，随机快变为随参信道；随参信道相关带宽 $\Delta f=1/\tau_m$，视线传播距离 $d\approx\sqrt{2rh}$（$r=6370$ km）。**香农公式**：

$$
C=B\log_2\left(1+\frac{S}{N}\right)=B\log_2\left(1+\frac{S}{n_0B}\right)\ (\text{b/s})
$$

$B\to\infty$ 时 $C\to1.44S/n_0$；由 $S=E_bR_b$ 推出香农极限 $E_b/n_0\ge\ln2\approx-1.6$ dB。这是所有编码与调制方案的终极标尺。

## 模拟调制

| 公式 | 含义 | 条件/易错 |
| --- | --- | --- |
| $s_{AM}=[A_0+m(t)]\cos\omega_ct$ | 标准调幅 | 必须 $A_0\ge\lvert m(t)\rvert_{\max}$，否则过调制 |
| $s_{DSB}=m(t)\cos\omega_ct$ | 抑制载波双边带 | 效率 100%，只能相干解调 |
| $s_{SSB}=\frac{1}{2}m(t)\cos\omega_ct\mp\frac{1}{2}\hat{m}(t)\sin\omega_ct$ | 单边带（相移法） | 上边带取 $-$，下边带取 $+$ |
| $B_{AM}=B_{DSB}=2f_H$，$B_{SSB}=f_H$ | 线性调制带宽 | VSB 略大于 $f_H$ |
| $\eta_{AM}=\frac{\overline{m^2}}{A_0^2+\overline{m^2}}$ | 调制效率 | 单音满调制时 $\eta=1/3$ |
| $G_{DSB}=2$，$G_{SSB}=1$，$G_{AM}\le2/3$ | 解调增益 | 同条件下 DSB 与 SSB 输出信噪比相同 |
| $m_f=\Delta f/f_m$ | 调频指数 | $\Delta f$ 为最大频偏 |
| $B_{FM}=2(m_f+1)f_m=2(\Delta f+f_m)$ | 卡森公式 | NBFM 约 $2f_m$；WBFM 约 $2\Delta f$ |
| $G_{FM}=3m_f^2(m_f+1)\approx3m_f^3$ | FM 解调增益 | 单音、鉴频、大信噪比；用带宽换信噪比 |

## 数字基带传输

| 公式 | 含义 | 条件/易错 |
| --- | --- | --- |
| $h(kT_B)=1\ (k=0)$，$=0\ (k\ne0)$ | 无 ISI 时域条件 | 总特性 $H=TCR$ |
| $\sum_iH\left(\omega+\frac{2\pi i}{T_B}\right)=T_B$ | 奈奎斯特第一准则 | 频域折叠叠加为常数 |
| $\eta_{\max}=2$ Baud/Hz | 理想低通极限 | 物理不可实现 |
| $B=(1+\alpha)\frac{R_B}{2}$，$\eta=\frac{2}{1+\alpha}$ | 升余弦滚降 | $0\le\alpha\le1$ |
| $P_e=\frac{1}{2}\mathrm{erfc}\left(\frac{d}{\sqrt{2}\sigma_n}\right)$ | 双极性误码率 | 单极性同峰值下差 6 dB |
| $C_k=a_k+a_{k-1}$，$b_k=a_k\oplus b_{k-1}$ | 第 I 类部分响应与预编码 | 无预编码会差错传播 |

## 数字带通传输：误码率总表

设解调器输入信噪比 $r=a^2/(2\sigma_n^2)$，等概、最佳门限：

| 方式 | 相干解调 | 非相干解调 |
| --- | --- | --- |
| 2ASK | $\frac{1}{2}\mathrm{erfc}\left(\sqrt{r/4}\right)$ | $\frac{1}{2}e^{-r/4}$ |
| 2FSK | $\frac{1}{2}\mathrm{erfc}\left(\sqrt{r/2}\right)$ | $\frac{1}{2}e^{-r/2}$ |
| 2PSK | $\frac{1}{2}\mathrm{erfc}\left(\sqrt{r}\right)$ | 无意义 |
| 2DPSK（相干 + 码反变换） | $\mathrm{erfc}\left(\sqrt{r}\right)$ | —— |
| 2DPSK（差分相干） | —— | $\frac{1}{2}e^{-r}$ |

记忆规律：**相干 erfc 型、非相干指数型；根号内分母 4→2→1 对应 ASK→FSK→PSK**。误码率排序 $P_{e,2PSK}<P_{e,2FSK}<P_{e,2ASK}$，相邻差 3 dB。带宽 $B_{2ASK}=B_{2PSK}=2f_B$，$B_{2FSK}=|f_2-f_1|+2f_B$（最宽）。

## 新型数字调制

| 公式 | 含义 | 条件/易错 |
| --- | --- | --- |
| $s_{QAM}=A_m\cos\omega_ct+B_m\sin\omega_ct$ | QAM（I/Q 两路 ASK） | 每符号 $\log_2M$ bit |
| $d_{16QAM}=\frac{\sqrt2}{3}A_M$，$d_{16PSK}\approx0.393A_M$ | 星座最小距离 | 平均功率相等时 16QAM 容限大 4.12 dB |

## 最佳接收

| 公式 | 含义 | 条件/易错 |
| --- | --- | --- |
| $H(f)=kS^*(f)e^{-j2\pi ft_0}$ | 匹配滤波器频域 | 信号频谱的复共轭 |
| $h(t)=ks(t_0-t)$ | 匹配滤波器时域 | 镜像 + 平移；$t_0\ge T_B$ 才因果 |
| $r_{0\max}=2E/n_0$ | 最大输出信噪比 | 只由能量与 $n_0$ 决定 |
| $P_e=\frac{1}{2}\mathrm{erfc}\left[\sqrt{\frac{E(1-\rho)}{2n_0}}\right]$ | 最佳接收误码率 | $\rho$ 为两波形相关系数 |
| $\lvert T(\omega)\rvert=\lvert R(\omega)\rvert=\lvert H(\omega)\rvert^{1/2}$ | 最佳基带收发分配 | 平方根升余弦 |

三种典型：2PSK（$\rho=-1$）为 $\frac{1}{2}\mathrm{erfc}\sqrt{E/n_0}$；2FSK（$\rho=0$）为 $\frac{1}{2}\mathrm{erfc}\sqrt{E/(2n_0)}$；2ASK 为 $\frac{1}{2}\mathrm{erfc}\sqrt{E/(4n_0)}$。

| 公式 | 含义 | 条件/易错 |
| --- | --- | --- |
| $f_s\ge2f_H$ | 低通抽样定理 | 恢复滤波器 $f_H\le B\le f_s-f_H$ |

## 差错控制编码

三条码距公式是所有纠错编码的出发点：

$$
\text{检 }e\text{ 错：}d_0\ge e+1;\qquad
\text{纠 }t\text{ 错：}d_0\ge2t+1;\qquad
\text{纠 }t\text{ 检 }e\ (e>t)：d_0\ge e+t+1
$$

| 公式 | 含义 | 条件/易错 |
| --- | --- | --- |
| $2^r\ge n+1$ | 汉明码条件 | $(7,4)$ 码 $r=3$ |
| $HA^T=0$，$A=MG$ | 监督/生成矩阵 | $H=[P\mid I_r]$，$G=[I_k\mid Q]$，$P=Q^T$ |
| $S=RH^T=EH^T$ | 伴随式 | $S\ne0$ 的图案指示错误位置 |
| $A(x)=x^{n-k}M(x)+R(x)$ | 循环码系统编码 | $R(x)$ 为除法余式 |
| $g(x)$ 是 $x^n+1$ 的 $r$ 次因子 | 生成多项式 | 全码字都是 $g(x)$ 的倍式 |

## 正交编码、伪随机序列与同步

| 公式 | 含义 | 条件/易错 |
| --- | --- | --- |
| $H_{2n}=\begin{bmatrix}H_n&H_n\\H_n&-H_n\end{bmatrix}$ | 哈达玛矩阵递推 | $H_nH_n^T=nI$，行两两正交 |
| $R(j)=1\ (j=0)$，$R(j)=-1/p\ (j\ne0)$ | m 序列双值自相关 | 周期 $p=2^n-1$ |
| $p=2^n-1$，本原多项式 | m 序列周期与产生条件 | 排除全 0 死锁状态 |
| $G_p=R_c/R_b=B_{SS}/B_{data}$ | 扩频处理增益 | 输出信噪比改善 $G_p$ 倍 |
| $P_1=1-\sum_{i=0}^{m}C_n^ip^i(1-p)^{n-i}$ | 漏同步概率 | $n$ 为同步码长、$p$ 为误码率 |
| $P_2=\frac{\sum_{i=0}^{m}C_n^i}{2^n}$ | 假同步概率 | $m$ 增大时 $P_1$ 降、$P_2$ 升 |
| 巴克码 $R(j)=n\ (j=0)$，$0$ 或 $\pm1\ (j\ne0)$ | 局部自相关 | 长度 2,3,4,5,7,11,13；7 位为 $1110010$ |

## 常用换算

| 换算 | 关系 | 备注 |
| --- | --- | --- |
| dB 与线性 | $X_{\text{dB}}=10\log_{10}X$ | 电压/幅度比用 $20\log_{10}$ |
| 噪声谱 | 双边 $n_0/2$，单边 $n_0$ | $\sigma_n^2=n_0B$ 用单边谱，混用差 3 dB |
| 速率 | $R_b=R_B\log_2M$ | QPSK：$R_B=R_b/2$ |
| $E_b/N_0$ 与 $S/N$ | $S/N=(E_b/N_0)(R_b/B)$ | 必须同时给出 $R_b/B$ 才能换算 |
| 香农极限 | $E_b/N_0\ge\ln2=-1.6\,\text{dB}$ | 带宽无限、无误传输的极限 |
| 卡森带宽 | $B_{FM}=2(\Delta f+f_m)$ | 调频广播例：$m_f=5$、$B=180$ kHz |
| 每位 6 dB | 量化信噪比随位数线性增长 | 每加 1 位改善约 6 dB |

## 跨库接口：这些公式从哪里来、到哪里去

通信原理不是孤岛：概率语言来自概率论、代数工具来自线性代数、工程落地在 5G、硬件实现在 FPGA。

| 通信原理 | 外部知识 | 接口 |
| --- | --- | --- |
| 高斯/瑞利/莱斯分布 | 概率论随机变量与分布 | 窄带噪声包络的统计模型；衰落信道建模 |
| 最大后验/最大似然 | 条件概率与贝叶斯公式 | $P(s_i/r)\propto P(r/s_i)P(s_i)$，MAP 即贝叶斯 |
| 线性分组码 $H$、$G$、$S$ | 线性方程组与矩阵运算 | 模 2 线性代数；$S$ 是投影到校验空间的残差 |
| 正交码、哈达玛矩阵 | 正交性与正交基 | $H_nH_n^T=nI$；沃尔什函数是正交基 |
| 时域均衡抽头求解 | 数值线性代数 | 迫零解线性方程组；MMSE 是正则化 |
| OFDM/CP、QAM、LDPC | 5G NR 物理层 | SCS 即 $\Delta f=1/T_s$；PDSCH 用 256QAM、LDPC |
| 码型、LFSR、科斯塔斯环 | FPGA/Verilog | AMI/HDB3 是移位寄存器 + 异或；m 序列即 LFSR |
| 误码率、眼图、星座 | MATLAB 仿真 | 用 berawgn、eyediagram、qammod 复现曲线与波形 |
| 相关、PSD、匹配滤波 | 随机信号处理子库 | 从概率到检测的完整链路 |

## 三条复习路线

1. **概率线**：概率论基本概念 → 随机变量与分布 → 随机过程 → 最佳接收（从分布走到接收机设计）；
2. **代数线**：线性方程组 → 线性分组码 → 正交码与扩频（模 2 线性代数 → 纠错码 → 扩频码）；
3. **工程线**：OFDM/QAM → 5G 空口 → 物理信道 → NR 规范（从原理走到工程参数）。

## 易错点

- 公式表里最容易错的是**条件**，不是表达式：噪声带宽、比较基准、门限、先验概率缺一不可。
- $r$ 与 $E_b/N_0$ 不是同一变量，换算依赖噪声带宽定义；跨调制比较必须统一自变量。
- 白噪声双边谱 $n_0/2$、单边谱 $n_0$，混用差 2 倍（3 dB）。
- 香农公式中的 $S/N$ 是线性值，题目给 dB 必须先换算。
- 卡森公式是工程近似，$m_f$ 很小时用 $2f_m$、很大时用 $2\Delta f$。
- 升余弦的 2 Baud/Hz 是 $\alpha=0$ 的极限值，任何滚降都会降低频带利用率。
- 漏同步/假同步公式共用容错门限 $m$，调参必须同时评估两个概率。
