# AD9361 数字接口

> [!abstract] 核心概念
> AD9361 的数字接口可以分成两条完全不同的通道：**SPI 是控制面**，负责配置寄存器和读取状态；**并行数据接口是数据面**，负责以实时、源同步的方式传输 RX/TX IQ 样本。SPI 通信成功，只能说明处理器能控制芯片，不能证明 FPGA 的 IQ 数据时序已经正确。

## 1. 数字接口在整颗芯片中的位置

AD9361 的完整数据流可以抽象为：

```text
                           控制面
                 SPI ↔ AD9361 寄存器 / 校准状态

天线 → RF/模拟链 → ADC → 数字抽取/FIR → 并行 RX IQ → FPGA
FPGA → 并行 TX IQ → 数字插值/FIR → DAC → 模拟链 → 天线
```

数字接口位于 AD9361 的数字基带和 FPGA 之间，主要解决以下问题：

- 何时采样一个 IQ 样本；
- 哪些数据位属于 I、Q 以及不同通道；
- 一帧数据从哪里开始；
- RX 和 TX 的时钟由谁提供；
- FDD/TDD 模式下收发方向如何切换；
- 数据采用 CMOS 还是 LVDS 电气标准；
- 数据在时钟单边沿还是双边沿传输。

### 1.1 三个概念不要混淆

| 概念 | 解决的问题 | 典型内容 |
| --- | --- | --- |
| SPI 控制接口 | 芯片如何被配置 | 频率、带宽、采样率、增益、FIR、校准 |
| 并行 IQ 数据接口 | 样本如何实时传输 | 数据总线、时钟、帧、使能、I/Q 排列 |
| FPGA 内部处理接口 | 样本进入逻辑后如何流动 | FIFO、AXI-Stream、DMA、FFT、解调模块 |

## 2. 两条数据路径：SPI 与 IQ 并行接口

### 2.1 SPI 控制面

SPI 用于访问 AD9361 内部寄存器和状态，常见控制内容包括：

- 复位后的初始化；
- FDD/TDD 工作模式；
- RX/TX LO 频率；
- RX/TX 模拟带宽；
- 基带采样率和时钟分频；
- RX/TX FIR 系数及插值/抽取倍率；
- 手动增益或 AGC 参数；
- 校准启动与状态读取；
- 数字接口模式和时序相关配置。

SPI 的数据量通常远小于 IQ 数据量，因此它不适合承载连续采样数据。配置完成后，IQ 数据仍然要通过专用的并行接口实时传输。

### 2.2 并行数据面

并行接口承载的是连续的时域样本。例如一个复采样时刻至少包含：

$$
x[n]=I[n]+jQ[n]
$$

如果有两个接收通道，则每个采样时刻可能包含：

$$
I_0[n],Q_0[n],I_1[n],Q_1[n]
$$

具体的物理引脚、数据打包、通道顺序和采样边沿取决于 CMOS/LVDS、SDR/DDR、FDD/TDD 以及单双端口等配置，不能只根据“12 位 ADC”推断接口上的固定排列。

## 3. 接口的四个维度

学习 AD9361 数字接口时，建议把配置拆成四个互相独立的维度。

### 3.1 CMOS 与 LVDS：电气层

**CMOS：**

- 单端逻辑电平；
- 原理和示波器观察比较直观；
- 高速时更容易受到地弹噪声、串扰和边沿质量影响；
- 多通道并行传输可能需要较多引脚。

**LVDS：**

- 差分传输；
- 对共模噪声和高速信号完整性更友好；
- 需要正确的差分布线、端接、极性和 FPGA I/O 标准配置；
- 调试时不能把差分对中的单根线当作普通 CMOS 信号理解。

CMOS/LVDS 只描述电气传输方式，不决定 IQ 数据的数学意义，也不单独决定使用单边沿还是双边沿。

### 3.2 SDR 与 DDR：时钟边沿

- **SDR（Single Data Rate）**：一个时钟周期使用一个有效边沿传输数据；
- **DDR（Double Data Rate）**：一个时钟周期的上升沿和下降沿都传输数据。

DDR 可以在不同比特率下减少时钟频率压力，但会增加采样沿、占空比、数据保持时间和 FPGA 输入逻辑的复杂度。使用 DDR 时，FPGA 往往需要 IDDR、ISERDES 或等效的双边沿采样结构。

SDR/DDR 是时序传输方式，不是 IQ 的采样率。最终有效 IQ 样本率仍应由“一个完整 IQ 样本需要多少数据边沿”推导，而不是直接把 `DATA_CLK` 当成 IQ 采样率。

### 3.3 FDD 与 TDD：收发调度

- **FDD**：RX 和 TX 可以同时保持活动，收发方向长期并行；
- **TDD**：在不同时间片切换 RX/TX，接口方向和射频状态需要协同。

FDD/TDD 是系统工作方式，不是 CMOS/LVDS 的替代选项。同一个 CMOS 或 LVDS 物理接口，都可能在不同收发模式下工作。

### 3.4 单端口与双端口：数据组织

AD9361 资料中会出现 `P0_D[11:0]`、`P1_D[11:0]` 等端口名称。端口数量、通道映射和每个边沿上的数据含义由接口配置决定。

不要直接假设：

- `P0` 一定对应 RX0；
- `P1` 一定对应 RX1；
- 一个总线上的 12 位一定永远只表示 I 或 Q；
- TX 和 RX 方向的排列完全相同。

正确做法是先确定接口模式，再根据 UG-570 对应模式的时序图和数据映射表解码。

## 4. 常见接口信号

UG-570 的数字接口章节会涉及以下典型信号名称。信号方向和精确时序会随工作模式变化，下面只说明学习时的功能角色。

| 信号 | 典型作用 | FPGA 设计时关注点 |
| --- | --- | --- |
| `P0_D[11:0]` | 并行数据端口 0 | 位宽、通道映射、I/Q 顺序 |
| `P1_D[11:0]` | 并行数据端口 1 | 是否启用、与 P0 的组合关系 |
| `DATA_CLK` | 数据采样相关时钟 | 时钟来源、有效边沿、占空比 |
| `FB_CLK` | 数据反馈/发送时钟相关信号 | TX 时序、相位和回采样关系 |
| `RX_FRAME` | RX 数据帧边界或样本组织指示 | 与数据边沿的对齐关系 |
| `TX_FRAME` | TX 数据帧边界或样本组织指示 | FPGA 输出数据的帧对齐 |
| `TXNRX` | TDD 收发方向控制相关信号 | 方向切换时序 |
| `ENABLE` | 数据接口使能相关控制 | 使能前后的空闲和首个有效样本 |

> [!warning] 不要只看信号名字猜方向
> 同一个信号在 RX、TX、FDD、TDD 或不同接口模式中可能承担不同的时序角色。最终应以芯片手册中与当前配置完全匹配的 timing diagram 为准，并结合评估板 HDL 约束确认实际连接。

## 5. IQ 数据到底如何组织

### 5.1 一个 IQ 样本不是一个实数

一个复采样时刻至少包含两个有符号数：

```text
I[n] + jQ[n]
```

因此，FPGA 中必须把 I 和 Q 视为一个不可拆分的样本对：

```text
sample[n] = {I[n], Q[n]}
```

如果 I、Q 经过了不同的 FIFO、不同的时钟域或不同的 `valid` 条件，就可能出现：

```text
I[n] + jQ[n-1]
```

这种错位通常不会表现为简单的“没有数据”，而会表现为星座散乱、镜像严重、解调 EVM 很大或频谱出现异常杂散。

### 5.2 有符号补码

ADC 输出和 FPGA 接收的数据通常应按有符号二进制补码理解。以 $N$ 位数据为例，其数值范围为：

$$
-2^{N-1}\leq x\leq2^{N-1}-1
$$

接入 FPGA 后应注意：

1. 先按照实际有效位宽进行符号扩展；
2. 不要把最高位当作普通幅度位；
3. 不要在无说明的情况下截掉符号位；
4. I、Q 使用相同的缩放、截位和饱和策略；
5. 乘法、平方和滤波累加必须增加内部位宽。

若正弦波的负半周突然变成很大的正数，通常优先检查补码解释和符号扩展。

### 5.3 数据帧与样本边界

帧信号的作用是帮助接收端确定“当前边沿上的数据属于哪个位置”。但帧边界不一定等同于一个完整的 `{I,Q}` 结构，可能还包含：

- 不同通道的交织；
- I/Q 的交替边沿；
- SDR/DDR 两个边沿上的不同半字；
- FDD/TDD 下的方向状态；
- 空闲周期或接口启动后的无效周期。

所以解码流程应当是：

```text
读取接口模式
    → 确认有效边沿
    → 找到 frame 的参考位置
    → 按手册映射位域
    → 组合 I/Q 和通道
    → 再送入后级算法
```

而不是直接把总线抓到的连续整数当作 I、Q 序列。

## 6. 时序原理

### 6.1 源同步接口

AD9361 数字接口通常采用随数据提供时钟或反馈时钟的源同步思想。接收端不应简单使用 FPGA 系统时钟去“猜测”外部数据何时稳定，而应：

1. 使用接口提供的相关时钟作为采样参考；
2. 根据手册确定上升沿或下降沿；
3. 检查数据相对于时钟的建立时间和保持时间；
4. 在 FPGA I/O 侧完成必要的延时、双边沿采样或串并转换；
5. 进入内部逻辑后再通过 FIFO 或 CDC 结构切换到处理时钟域。

### 6.2 建立时间与保持时间

在有效采样边沿附近，数据需要提前稳定并在边沿之后保持一段时间：

```text
数据  ────────[稳定窗口]────────
时钟  ________/‾‾‾‾‾‾‾‾‾‾‾\____
                 ↑
              有效采样沿
```

如果数据边沿和时钟边沿太接近，可能出现：

- 同一数据在不同板卡上读到不同值；
- 温度或电压变化后误码增多；
- ILA 中偶发跳变；
- 固定测试值变成随机错误值；
- 只有某些 bit 错误，且错误与边沿相关。

### 6.3 时钟相位与采样窗口

高速接口调试的目标不是让时钟“看起来漂亮”，而是让采样边沿落在数据眼图的中心区域。实际设计中需要综合考虑：

- AD9361 输出时钟和数据的相位关系；
- FPGA 封装和 PCB 走线延迟；
- 差分对内 skew 和各数据位之间的 skew；
- FPGA I/O 延迟资源；
- 时钟占空比；
- DDR 两个边沿的有效窗口。

### 6.4 FPGA 约束的基本思路

具体约束语法取决于 FPGA 厂商和工具，但思路通常包括：

- 为外部数据时钟建立时钟约束；
- 为数据和帧信号添加输入/输出延迟约束；
- 指定正确的 CMOS 或 LVDS I/O 标准；
- 对差分时钟和差分数据指定正确的 P/N 引脚；
- 使用器件手册建议的 I/O 采样原语；
- 检查实现后的 setup/hold slack，而不是只看 RTL 仿真。

## 7. RX 数据采集路径

RX 方向的 FPGA 逻辑可以按层划分：

```text
AD9361 RX pins
    ↓
I/O buffer / differential receiver
    ↓
SDR/DDR capture
    ↓
frame-based unpacker
    ↓
I/Q sign extension
    ↓
channel alignment
    ↓
CDC FIFO
    ↓
AXI-Stream / user processing clock
    ↓
DDC、FFT、解调或 DMA
```

### 7.1 RX 端不要过早改变数据

刚采集进 FPGA 的数据建议保留一份原始副本，用于：

- ILA 观察；
- 写入片外存储；
- 与 Python 或 MATLAB 参考结果比较；
- 检查位宽和符号；
- 判断问题来自接口还是来自后级算法。

如果一进入 FPGA 就做了复杂缩放、滤波或重排，出现问题时很难定位是哪个环节造成的。

### 7.2 RX 端 CDC

外部接口时钟通常不是 FPGA 算法时钟。正确结构一般是：

```text
接口时钟域采集
    → 小 FIFO / 异步 FIFO
    → FPGA 内部处理时钟域
```

不要直接把接口时钟域中的多位 I/Q 总线用两级触发器逐 bit 同步。多位总线逐 bit 同步可能造成各 bit 在不同周期完成同步，导致数据字撕裂。

## 8. TX 数据发送路径

TX 方向通常需要反向完成：

```text
用户算法 / DMA
    ↓
内部处理时钟域
    ↓
异步 FIFO / 速率匹配
    ↓
I/Q 配对与帧生成
    ↓
TX 接口时钟域
    ↓
SDR/DDR launch
    ↓
AD9361 TX pins
```

### 8.1 TX 数据必须连续可预测

发送端常见问题包括：

- FIFO 空导致欠载；
- AXI-Stream 暂停导致接口出现空洞；
- I 和 Q 的 `valid` 不一致；
- 帧信号与数据提前或滞后一个边沿；
- 复位后第一个样本位置不确定。

对于连续波形，应在启动发射前先填充 FIFO，并明确欠载时输出什么。对于突发波形，应把“无效区、保护间隔、首个有效样本”设计成明确的状态机。

### 8.2 发射数据幅度

TX IQ 样本的数字幅度会影响 DAC 输入幅度以及后续模拟链路的输出功率，但数字满量程不等于射频端允许的最大功率。需要同时检查：

- FPGA IQ 数值范围；
- FIR 系数增益；
- DAC 满量程；
- AD9361 TX 模拟增益；
- 外部衰减器和功放；
- 波形 PAPR 和峰值削顶。

## 9. FDD 与 TDD 接口时序

### 9.1 FDD 数据流

在 FDD 中，RX 和 TX 可能同时运行：

```text
RX 数据时钟/帧  → FPGA RX 采集
TX 数据时钟/帧  ← FPGA TX 发送
```

调试时要分别验证两条路径，不能因为 RX 正常就认为 TX 时序也正确。两者可能具有不同的：

- 数据方向；
- 时钟来源；
- 帧信号方向；
- 数据有效边沿；
- 通道映射；
- 使能条件。

### 9.2 TDD 数据流

TDD 中，`TXNRX`、`ENABLE` 和帧/时钟信号需要共同决定当前方向。可以把它理解为一个时序状态机：

```text
IDLE
  → RX_ACTIVE
  → TURNAROUND
  → TX_ACTIVE
  → TURNAROUND
  → RX_ACTIVE
```

每次切换都要考虑：

- RF 模拟链路的稳定时间；
- 数字接口方向切换时间；
- FPGA 数据 FIFO 的排空和填充；
- 首个有效 IQ 样本的相位/帧位置；
- 外部射频开关和功放的使能时序。

不要只在软件里改变一个 TX/RX 标志，而不观察硬件时序信号。

## 10. 数据吞吐率估算

### 10.1 基本公式

若有 $N_{ch}$ 个通道，每个通道包含 I、Q 两个分量，每个分量为 $N_{bit}$ 位，复采样率为 $F_s$，则原始有效负载速率约为：

$$
R_{payload}=N_{ch}\times2\times N_{bit}\times F_s
$$

这个速率还没有计入：

- 帧和空闲周期；
- 对齐填充；
- DMA 描述符；
- AXI 或 PCIe 打包开销；
- 内存读写效率；
- 软件缓冲和协议开销。

### 10.2 例子

假设两个通道、每通道 I/Q 各 12 位、复采样率为 30.72 MSPS，则有效 IQ 负载约为：

$$
R_{payload}=2\times2\times12\times30.72\ \text{Mbit/s}
=1.47456\ \text{Gbit/s}
$$

这说明即使每个样本只有 12 位，双通道高速 IQ 也会迅速占满 FPGA 内部总线、DMA 和存储带宽。工程中常把数据扩展为 16 位对齐，实际搬运带宽还会进一步增加。

### 10.3 时钟频率不等于吞吐率

DDR 可以在一个时钟周期传输两组数据，因此可能降低物理时钟频率，但不会减少每秒必须传输的有效 IQ 比特数。分析系统带宽时要分别记录：

- 有效 IQ 样本率；
- 每样本有效位数；
- 物理总线宽度；
- 每周期有效边沿数；
- 总线空闲和填充比例。

## 11. FPGA 端推荐的解包结构

建议把接口逻辑分为几个独立模块：

```text
ad9361_io_capture
    ↓
ad9361_frame_align
    ↓
ad9361_iq_unpack
    ↓
ad9361_signed_extend
    ↓
ad9361_channel_align
    ↓
ad9361_cdc_fifo
    ↓
ad9361_stream_adapter
```

### 11.1 `io_capture`

负责：

- CMOS/LVDS 输入；
- SDR/DDR 采样；
- 时钟和数据边沿；
- 必要的 I/O 延迟。

### 11.2 `frame_align`

负责：

- 识别 RX/TX frame；
- 建立样本边界；
- 处理复位后的初始相位；
- 检测帧与数据不一致。

### 11.3 `iq_unpack`

负责：

- 从总线位域提取 I、Q；
- 恢复多通道顺序；
- 处理 SDR/DDR 的交替数据；
- 产生一个明确的 `iq_valid`。

### 11.4 `channel_align`

负责保证：

```text
I0[n]、Q0[n]、I1[n]、Q1[n]
```

属于同一个采样编号 `n`。建议给每个输出样本附加递增 sample counter，便于在 ILA 或软件中发现丢样本和错位。

## 12. 建议的接口调试测试模式

### 12.1 固定值测试

```text
I = 1000
Q = 0
```

用途：

- 检查 I/Q 位宽；
- 检查 Q 是否被错误读取；
- 检查符号扩展；
- 检查固定值是否在每个边沿稳定。

### 12.2 交替测试

```text
I[n] = +C, -C, +C, -C, ...
Q[n] = 0
```

用途：

- 检查样本顺序；
- 检查漏采或重复采样；
- 检查 DDR 上升沿/下降沿是否反了。

### 12.3 斜坡测试

```text
I[n] = n
Q[n] = -n
```

用途：

- 检查多位总线是否发生 bit 错位；
- 检查帧边界；
- 检查通道交织；
- 检查 FIFO 中是否丢样本。

### 12.4 复单音测试

$$
I[n]=A\cos\left(2\pi\frac{f_b}{F_s}n\right)
$$

$$
Q[n]=A\sin\left(2\pi\frac{f_b}{F_s}n\right)
$$

用途：

- 检查 I/Q 是否同拍；
- 检查相位是否约为 $90^\circ$；
- 检查频谱正负方向；
- 检查射频 LO 搬移方向；
- 检查镜像抑制。

## 13. 典型错误的波形特征

| 观察到的现象 | 可能原因 |
| --- | --- |
| 全部为 0 | 接口未使能、时钟未启动、帧条件错误、RX 无有效数据 |
| 数据只有正数 | 符号位丢失或按无符号数解释 |
| 正弦波负半周变成大正数 | 补码未符号扩展 |
| I 和 Q 互换 | 数据映射或解包顺序错误 |
| Q 取反后频谱方向反了 | Q 符号约定不一致 |
| 每隔一个样本异常 | SDR/DDR 边沿使用错误或半字拼接错误 |
| 所有 bit 看起来整体左/右移 | 位对齐或采样沿错误 |
| 只在高采样率出错 | setup/hold 裕量不足或 PCB 信号完整性问题 |
| 固定值正确、随机数据错误 | 时序窗口、串扰、FIFO 或 CDC 问题 |
| 单通道正常、双通道错位 | P0/P1 映射或通道帧组织错误 |
| RX 正常、TX 无输出 | TX frame/FB_CLK/数据方向/使能配置错误 |
| 复位后第一个样本错位 | frame 初始状态没有同步 |
| 长时间运行后出现断点 | FIFO 溢出、DMA 丢包、时钟频率不匹配 |

## 14. 推荐的上电与联调顺序

### 第一步：确认硬件连接

- 芯片型号和评估板型号；
- 参考时钟频率；
- CMOS 还是 LVDS；
- 差分 P/N 是否接反；
- 数据端口和帧/时钟引脚连接；
- FPGA I/O 电压标准；
- 是否存在外部电平转换或隔离器件。

### 第二步：只验证 SPI

- 确认复位状态；
- 读取已知寄存器；
- 写入后回读可验证寄存器；
- 记录初始化日志和校准状态；
- 不要在 SPI 尚未稳定时排查 FPGA IQ 时序。

### 第三步：确认时钟与接口模式

- 确认参考时钟已被芯片识别；
- 确认 RX/TX 采样率；
- 确认 CMOS/LVDS、SDR/DDR、FDD/TDD；
- 确认接口相关使能和帧配置；
- 确认 FPGA 约束已生效。

### 第四步：使用固定或斜坡数据

先不要直接使用 QAM、OFDM 等复杂波形。使用固定值、交替值和斜坡值，配合 ILA 检查：

- 时钟边沿；
- frame 边界；
- bit 对齐；
- I/Q 组合；
- 通道顺序；
- CDC 和 FIFO。

### 第五步：使用复单音

确认时域 IQ、复 FFT、星座图和射频频谱之间互相一致。复单音是连接“数字接口问题”和“射频链路问题”的最小测试信号。

### 第六步：最后引入复杂系统

在接口基础稳定后，再增加：

- DMA 和 DDR 存储；
- AXI-Stream；
- DDC/DUC；
- AGC；
- TDD 切换；
- 数字调制与解调；
- 高层协议。

## 15. ILA/逻辑分析仪应该抓什么

最小推荐抓取信号：

```text
接口数据时钟
RX_FRAME / TX_FRAME
TXNRX
ENABLE
P0_D[11:0]
P1_D[11:0]
解包后的 I/Q
iq_valid
FIFO 写入/读出计数
溢出/欠载标志
sample_counter
```

建议同时设置三类触发条件：

1. 复位释放后的第一次有效帧；
2. `iq_valid` 出现但数据不符合测试模式；
3. FIFO 溢出、欠载或 sample counter 不连续。

抓取原始接口信号和解包后信号，可以迅速判断错误发生在：

```text
物理引脚 → I/O 采样 → 帧解码 → 符号扩展 → FIFO/CDC → 后级算法
```

## 16. 设计时的原则

1. **先按手册解码，再按波形猜测。** 波形看起来像正弦，不代表 I/Q 顺序和采样沿正确。
2. **先验证一个通道，再扩展到双通道。** 双通道会引入额外的映射和吞吐率问题。
3. **先验证接口时钟域，再验证算法时钟域。** 不要用后级 FFT 的结果替代接口时序验证。
4. **I/Q 必须成对处理。** 不能让两路独立经过不相同的延迟、FIFO 或有效条件。
5. **把采样率、接口时钟和处理时钟分别记录。** 三者可能不同。
6. **保留原始数据抓取路径。** 调试时不要只保留经过算法处理后的数据。
7. **所有配置都要和芯片型号、接口模式及驱动版本对应。** 不要直接复制网上的寄存器表。
8. **数字接口校准和 RF 校准是两件事。** LVDS PRBS 正确，不代表射频 IQ 失衡已经校准；射频输出正常，也不代表高速接口没有时序裕量问题。
