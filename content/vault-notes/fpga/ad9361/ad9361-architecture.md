# AD9361 学习笔记

> [!abstract] 先记住一句话
> AD9361 是一颗高度集成的宽带射频收发器。它负责射频信号与复基带 IQ 数据之间的转换、模拟/数字滤波、采样率转换、增益控制、频率合成和校准；FPGA 或处理器主要负责基带算法、数据搬运、协议和上层控制。理解 AD9361 的关键，不是死记寄存器，而是先建立“射频频率—模拟基带—ADC/DAC—数字滤波—FPGA IQ 数据”这条完整信号链。

## 1. AD9361 是什么

### 1.1 芯片定位

AD9361 属于宽带、可编程、直接变频（Zero-IF）架构的 RF Agile Transceiver，面向软件无线电和 2×2 MIMO 系统。它把过去需要多颗芯片完成的功能集成在一起：

- 两路接收（RX）射频通道；
- 两路发送（TX）射频通道；
- 接收机和发射机的正交混频器；
- 接收 ADC 与发送 DAC；
- 模拟基带滤波器；
- 可编程数字 FIR、半带滤波器以及抽取/插值链；
- 接收增益控制和 RSSI 相关功能；
- RX、TX 射频频率合成器；
- 基带 PLL（BBPLL）和数字时钟链；
- 片上校准功能；
- 面向 FPGA/处理器的 CMOS 或 LVDS 数字数据接口；
- SPI 控制接口。

因此，AD9361 不是“一个高速 ADC 加一个高速 DAC”，而是从天线端到复基带接口的一整套可配置收发机。

### 1.2 常用关键规格

| 项目 | 典型信息 | 学习时的含义 |
| --- | --- | --- |
| RX 射频频率范围 | 约 70 MHz～6.0 GHz | 接收 LO 决定射频搬移到哪个频段 |
| TX 射频频率范围 | 约 47 MHz～6.0 GHz | 发射 LO 决定 IQ 信号被搬移到哪个频段 |
| 通道带宽 | 从窄带配置到 56 MHz 级别 | 由模拟滤波器、数字 FIR 和采样率共同决定 |
| 转换器 | 12 位 ADC、12 位 DAC | 射频模拟量与数字 IQ 之间的量化接口 |
| 数字 FIR | 可编程 128-tap FIR | 用于通道选择、补偿和采样率转换 |
| 数字接口 | CMOS 或 LVDS 并行接口 | 连接 FPGA/处理器的实时 IQ 数据通道 |
| 控制接口 | SPI | 配置寄存器，不是高速 IQ 数据通道 |
| 工作模式 | FDD、TDD | 决定收发是同时工作还是按时隙切换 |

具体数值应以所使用版本的数据手册和硬件配置为准。尤其要区分芯片规格、评估板规格和实际射频前端的规格。

## 2. 先建立整体信号链

### 2.1 接收方向 RX

```text
天线 / 外部射频
    ↓
RX 射频输入与模拟前端
    ↓
RX 射频 PLL 产生本振
    ↓
正交下变频：RF → I/Q 模拟基带
    ↓
模拟基带低通滤波与增益控制
    ↓
I/Q ADC
    ↓
数字抽取与 RX FIR
    ↓
数字接口时钟与数据打包
    ↓
FPGA / 处理器得到 I[n]、Q[n]
```

接收机并不是直接以 ADC 采样 2.4 GHz 或 5.8 GHz 的射频载波，而是先用本振把目标信道搬移到零中频附近，再分别采样 I、Q 两路基带信号。

### 2.2 发射方向 TX

```text
FPGA / 处理器产生 I[n]、Q[n]
    ↓
数字接口接收与数据解包
    ↓
TX FIR 与数字插值
    ↓
I/Q DAC
    ↓
模拟基带滤波与增益控制
    ↓
正交上变频：I/Q 基带 → RF
    ↓
TX 射频输出与外部功放/天线
```

TX 方向是 RX 的逆过程，但模拟器件、时钟路径、滤波器顺序和校准项目并不完全相同。

### 2.3 AD9361 与 FPGA 的分工

| 功能 | AD9361 主要负责 | FPGA/处理器主要负责 |
| --- | --- | --- |
| 射频频率搬移 | RF PLL、正交混频器 | 通常不直接处理射频载波 |
| 模拟信号处理 | LNA、TIA、模拟 LPF、PA 驱动 | 通常不负责模拟滤波 |
| 转换 | ADC、DAC | 接收/发送数字样本 |
| 采样率转换 | 半带滤波、FIR、抽取/插值 | 可继续做 DDC、DUC、重采样 |
| IQ 校准 | 芯片内部校准与跟踪 | 可做系统级补偿和测量 |
| 基带算法 | 提供数据接口 | 解调、调制、同步、FFT、协议 |
| 配置 | SPI 寄存器 | 驱动、设备树、libiio 或 No-OS API |

## 3. 直接变频与 IQ 的关系

### 3.1 为什么使用零中频

假设接收目标中心频率为 $f_{RF}$，RX 本振设置为 $f_{LO}=f_{RF}$，混频后目标信号被搬移到 $0$ Hz 附近：

$$
f_{BB}=f_{RF}-f_{LO}\approx0
$$

目标信号的上下边带分别变成复基带的正、负频率。用 IQ 表示后，可以区分两个方向：

$$
x(t)=I(t)+jQ(t)
$$

理想正交解调满足：

$$
s_{RF}(t)=I(t)\cos(\omega_{LO}t)-Q(t)\sin(\omega_{LO}t)
$$

接收端再分别与余弦和正弦本振相乘并低通，就能恢复 I、Q。

更完整的数学推导见 [[vault-notes/fpga/ad9361/iq-signals]]。在学习 AD9361 时，应把芯片理解为一个将射频实信号与复基带 IQ 信号互相转换的硬件系统。

### 3.2 零中频的优点和代价

**优点：**

- 结构相对直接，不需要复杂的固定中频滤波器；
- 适合宽带可编程 SDR；
- 数字接口直接输出复基带 IQ；
- 便于实现可调中心频率和可调信道带宽。

**代价：**

- LO 泄漏可能在零频处形成 DC 尖峰；
- I/Q 增益或相位不匹配会产生镜像；
- 直流偏置会污染零频附近的信号；
- 低频噪声和闪烁噪声可能影响近 DC 信号。

## 4. 接收链路的内部结构

### 4.1 RX 射频与模拟基带

接收的射频信号首先经过输入匹配、低噪声放大和混频。正交混频器使用相差 $90^\circ$ 的本振，将信号分解为 I、Q 两路模拟基带。

混频后的模拟基带还需要经过：

- 模拟低通滤波，限制进入 ADC 的带宽；
- TIA 等模拟基带增益级；
- 可编程增益控制；
- ADC 前的幅度和带宽调整。

模拟滤波器不是数字 FIR 的替代品。模拟滤波器负责在 ADC 之前抑制带外信号和混叠风险，数字 FIR 则主要负责数字域的通道选择、补偿和抽取。

### 4.2 RX ADC 与数字抽取

RX ADC 将 I/Q 模拟电压量化为有符号数字样本。ADC 后的内部数字时钟通常高于最终输出的基带数据率，因此需要经过抽取滤波器降低数据率。

UG-570 给出的 RX 滤波链可以概括为：

```text
RX ADC
  → HB3 / DEC3
  → HB2
  → HB1
  → RX FIR
  → 数字接口
```

不同级可以根据配置旁路或选择不同的倍率。概念上，接收基带采样率满足：

$$
F_{BB,RX}=\frac{F_{ADC}}{D_{HB3}D_{HB2}D_{HB1}D_{FIR}}
$$

其中每个 $D$ 表示对应级的抽取倍率。这个公式用于理解时钟关系，实际可用组合受 AD9361 支持的滤波器配置限制。

### 4.3 RX FIR 的作用

RX FIR 是可编程有限冲激响应滤波器，可以用于：

- 限制最终接收带宽；
- 抑制邻道和带外噪声；
- 补偿模拟滤波器和半带滤波器的幅频响应；
- 配合抽取降低输出 IQ 数据率；
- 调整通带纹波、阻带衰减和过渡带。

FIR 系数不是独立于系统参数的“万能系数”。修改采样率、信道带宽、抽取倍率或模拟滤波器配置后，原来的系数可能不再适合。

## 5. 发射链路的内部结构

### 5.1 TX 数字插值

FPGA 输出的 IQ 采样率通常低于 DAC 所需的内部采样率，因此 TX 方向需要插值。TX 滤波链可以概括为：

```text
数字接口
  → TX FIR
  → HB1
  → HB2
  → HB3 / INT3
  → TX DAC
```

概念上，发送 DAC 采样率满足：

$$
F_{DAC}=F_{BB,TX}I_{FIR}I_{HB1}I_{HB2}I_{HB3}
$$

其中 $I$ 表示插值倍率。RX FIR 支持的抽取选项、TX FIR 支持的插值选项以及 HB3/INT3 的倍率需要按照 UG-570 的允许组合配置。

### 5.2 TX FIR 的作用

TX FIR 主要用于：

- 对发送 IQ 数据进行脉冲成形；
- 限制发射占用带宽；
- 降低邻道泄漏；
- 补偿 DAC、半带滤波器和模拟基带链的频响；
- 与插值链配合，将 FPGA 数据率转换为 DAC 数据率。

对于 QPSK、QAM 等数字调制，TX FIR 往往还承担根升余弦等脉冲成形功能。对于宽带波形，必须同时考虑 FIR tap 数、系数缩放、群时延和 FPGA 端的符号率/采样率。

> [!warning] 不要只加载系数而不核对速率
> FIR 系数必须和实际的基带采样率、RF 带宽、插值/抽取配置以及模拟滤波配置一起验证。配置完成后最好用已知单音、扫频或调制波形测量实际通带和阻带。

## 6. 频率、带宽、采样率：最容易混淆的三组概念

### 6.1 射频中心频率

射频中心频率由 RF PLL 和本振设置决定，例如：

$$
f_{LO}=2.4\ \text{GHz}
$$

它描述的是信号位于哪一个无线电频段，不等于 FPGA 处理的采样率。

### 6.2 IQ 复采样率

IQ 复采样率 $F_s$ 表示 I、Q 两路每秒各有多少个样本。假设复基带占据：

$$
[-B/2,+B/2]
$$

理想情况下至少需要：

$$
F_s\ge B
$$

工程中还需为滤波器过渡带、时钟误差和抗混叠留出余量。

### 6.3 信道带宽

信道带宽描述允许通过的基带频谱宽度。它受多个模块共同影响：

```text
RF 前端带宽
    ∩ 模拟基带滤波器带宽
    ∩ 数字 FIR 通带/阻带
    ∩ ADC/DAC 采样率允许的奈奎斯特范围
```

所以设置了一个 20 MHz 的数字 FIR 通带，并不意味着天线端一定就得到理想的 20 MHz 射频信道；还要检查模拟滤波器、采样率、增益、外部射频前端和实际频谱。

### 6.4 一个频率搬移例子

在约定 $x[n]=I[n]+jQ[n]$、射频表达式为 $\operatorname{Re}\{x(t)e^{j\omega_ct}\}$ 时：

- 基带复单音 $e^{+j2\pi f_bn/F_s}$ 被搬到 LO 上方；
- 基带复单音 $e^{-j2\pi f_bn/F_s}$ 被搬到 LO 下方。

例如 LO 为 2.4 GHz、基带单音为 $+1$ MHz，则理想目标频率为 2.401 GHz。若实际频谱出现在 2.399 GHz，应优先检查 Q 符号、I/Q 顺序、NCO 方向和接口数据解释。

## 7. 时钟体系

### 7.1 三类容易混淆的频率

AD9361 中至少要区分：

1. **外部参考时钟**：提供芯片 PLL 的参考；
2. **RF PLL 输出的本振频率**：用于 RX/TX 射频上变频或下变频；
3. **BBPLL 及其分频时钟**：用于 ADC/DAC、数字滤波器和数据接口相关时钟。

RF PLL 决定“信号搬到哪里”，BBPLL 和数字分频链决定“数据以多快的速度处理”。

### 7.2 BBPLL 的作用

UG-570 描述的 BBPLL 工作范围约为 715 MHz～1.430 GHz。BBPLL 之后通过可编程分频器产生 ADC、DAC、数字处理和接口所需的时钟。

因此，设置一个新的 IQ 采样率时，实际不是只改一个寄存器，而是要找到一组相互匹配的：

- BBPLL 频率；
- ADC/DAC 时钟；
- 半带滤波器倍率；
- FIR 抽取/插值倍率；
- FPGA 数据接口时钟；
- 模拟滤波器和信道带宽参数。

### 7.3 时钟配置的思考顺序

建议按照以下顺序理解或设计：

```text
目标 RF 带宽
    → 目标 IQ 采样率
    → 选择 FIR 抽取/插值
    → 选择半带滤波器组合
    → 反推 ADC/DAC 时钟
    → 选择 BBPLL 与分频器
    → 检查数字接口速率和 FPGA 时序
```

改变其中任意一个环节，都应重新核对整条时钟链。

## 8. 数字接口与 FPGA 对接

### 8.1 两个接口的职责

**SPI 控制接口：**

- 写入工作频率、带宽、增益和模式；
- 配置 FIR 系数及滤波器倍率；
- 启动或读取校准；
- 读取状态和错误信息。

**并行数据接口：**

- 实时传输 RX IQ 样本；
- 接收 TX IQ 样本；
- 使用独立的时钟、帧信号和使能信号描述数据时序。

SPI 配置成功不代表 IQ 数据接口时序一定正确；反过来，FPGA 能收到数据也不代表射频链路已经正确校准。

### 8.2 需要重点认识的信号

UG-570 的数字接口章节涉及以下典型信号名称：

- `P0_D[11:0]`、`P1_D[11:0]`：并行数据端口；
- `DATA_CLK`：数据时钟；
- `FB_CLK`：反馈时钟；
- `RX_FRAME`、`TX_FRAME`：接收/发送帧指示；
- `TXNRX`：TDD 收发方向控制；
- `ENABLE`：接口或数据使能相关控制。

实际数据在 CMOS/LVDS、单端/差分、SDR/DDR、FDD/TDD 等配置下的排列和采样沿可能不同，必须以当前配置对应的时序图为准。

### 8.3 FPGA 端的检查清单

- I 和 Q 是否来自同一个采样时刻；
- 是否正确识别帧边界；
- 上升沿/下降沿采样是否符合配置；
- 数据是否按 12 位有符号补码解释；
- 高位和低位是否发生错位；
- I/Q 是否交换或 Q 被取反；
- `valid`、帧信号和数据是否同拍；
- TX 端是否连续提供有效数据；
- RX 端是否因 FIFO、DMA 或 AXI-Stream 回压丢样本；
- 复位释放后是否等待接口进入稳定状态。

### 8.4 LVDS 接口校准

LVDS 数据接口的采样窗口、PCB 走线、时钟相位和数据延时都会影响可靠性。Analog Devices 的 AN-1441 专门讨论 AD9361 LVDS 接口的 PRBS 校准，可将它作为 FPGA 接口调试的专项参考，而不要只靠观察随机 IQ 波形判断接口是否正确。

## 9. FDD、TDD 与状态控制

### 9.1 FDD

FDD 中 RX 和 TX 可以在不同频率上同时工作，通常适用于上下行频率分开的系统。此时需要同时关注：

- RX 和 TX 各自的 RF PLL；
- 发射泄漏对接收链路的影响；
- 两条数据流的时钟和缓冲；
- 外部双工器、隔离度和功率配置。

### 9.2 TDD

TDD 在不同时间片使用同一套或相关射频资源进行发送和接收。`TXNRX`、`ENABLE` 以及相关帧/时钟信号参与收发切换。

TDD 调试时要同时观察：

1. 收发切换时刻；
2. RF PLL 和模拟前端稳定时间；
3. FPGA 数据帧是否与方向切换对齐；
4. 切换期间是否产生无效样本或突发杂散；
5. 外部功放、开关和天线通道是否同步。

## 10. 初始化与校准

### 10.1 为什么必须校准

AD9361 内部存在模拟器件偏差、PLL VCO 偏差、I/Q 增益和相位误差、ADC/DAC 偏移以及不同温度和频率下的变化。校准的目的不是“让芯片能启动”这么简单，而是建立满足当前频率、带宽、采样率和工作模式的模拟与数字工作点。

### 10.2 UG-570 涉及的校准类型

官方参考手册中涉及的校准大致包括：

- BBPLL VCO 校准；
- RX/TX RF synthesizer 的电荷泵和 VCO 校准；
- RX/TX 模拟滤波器调谐；
- RX TIA 和 ADC 相关设置；
- 基带 DC offset 校准；
- RF DC offset 校准；
- RX/TX quadrature 校准；
- 与接收增益和工作状态相关的跟踪校准。

校准具体由初始化流程和配置参数触发，不能简单理解为所有项目每次都用同一种方式手动执行。

### 10.3 建议的初始化思路

```text
上电并稳定电源
    → 提供并确认参考时钟
    → 复位 AD9361
    → SPI 建立通信
    → 配置工作模式（FDD/TDD）
    → 配置时钟与采样率
    → 配置 RX/TX FIR 及模拟带宽
    → 设置 RX/TX LO
    → 执行所需初始化校准
    → 配置增益、AGC 和功率
    → 使能数字接口
    → 发送/接收已知 IQ 测试数据
```

实际软件可能把上述步骤封装在驱动初始化函数中。学习时要把 API 调用重新映射回这些硬件步骤，才能理解初始化日志和失败原因。

### 10.4 频率改变后的校准

部分校准与当前 LO、滤波器和模拟工作点相关。大幅改变 LO（参考手册讨论了例如超过 100 MHz 的变化情形）后，不能假设上一次校准结果永远有效，应依据驱动和 UG-570 的触发规则重新执行相关校准。

## 11. 增益、AGC 与信号幅度

### 11.1 接收增益不等于信号质量

提高 RX 增益可以让小信号占据更多 ADC 码值，但也会同时放大噪声和强干扰。增益过高会导致：

- ADC 饱和；
- IQ 波形削顶；
- 互调和杂散上升；
- EVM 恶化；
- AGC 频繁动作。

增益过低则会使量化噪声和后级固定点噪声占比变大。

### 11.2 AGC 调试方法

调试初期建议先使用可控的手动增益和已知输入功率，确认链路基本正确后再启用 AGC。启用 AGC 后需要观察：

- RSSI 是否随输入功率变化；
- 增益是否在期望范围内变化；
- 强信号出现时是否及时回退；
- 弱信号时是否把噪声误当作有用信号；
- 收发切换或突发信号期间是否产生增益瞬态。

## 12. 常见现象与排查路径

| 现象 | 优先检查项目 |
| --- | --- |
| SPI 能读写但没有 RX 数据 | 接口使能、时钟、帧信号、工作模式、校准状态、FPGA 采样沿 |
| RX 有数据但全是零 | RX 通道状态、输入连接、增益、数据有效信号和 DMA 缓冲 |
| IQ 波形有数据但频谱方向反了 | Q 取反、I/Q 顺序、复数符号约定、FFT 频率方向 |
| 频谱中心有明显尖峰 | LO 泄漏、DC offset、直流校准、零中频本身的低频噪声 |
| 出现对称镜像 | I/Q 增益失衡、相位失衡、时延不匹配或数据解包错误 |
| 频率位置正确但带宽不对 | RF 带宽、模拟 LPF、FIR 系数、抽取/插值和采样率组合 |
| 频谱整体偏移 | RF LO、参考时钟、频率规划或外部仪器频率设置 |
| IQ 样本偶发跳变 | DDR 采样时序、LVDS 窗口、位对齐、FIFO 溢出或数据丢失 |
| 发射功率很低 | TX 增益、TX 端口、外部衰减器、功放使能、DAC 数据幅度 |
| 发射波形削顶 | FPGA 缩放、FIR 增益、DAC 满量程、TX 模拟增益和外部功放 |
| 改变采样率后频响异常 | FIR 系数与新的采样率/带宽/滤波器链不匹配 |
| 改变 LO 后性能突然变差 | 相关 RF PLL 或跟踪校准未重新执行 |

### 12.1 推荐的最小化调试顺序

1. 只检查 SPI：读写一个稳定的识别或状态寄存器；
2. 不接复杂射频信号，先确认参考时钟、复位和初始化校准；
3. 用内部或外部已知单音确认 RX 数据能进入 FPGA；
4. 在 FPGA 中直接观察 I、Q 时域波形和复 FFT；
5. 检查 I/Q 顺序、符号和采样率；
6. 再检查 LO、信道带宽、FIR 和增益；
7. 最后才引入 AGC、TDD 时序、DMA、高速协议和复杂调制波形。

## 13. 适合 FPGA 学习的验证实验

### 实验一：验证数字接口

向 TX 端发送固定值：

$$
I[n]=C,\qquad Q[n]=0
$$

观察 RX 或回环数据的位宽、符号、帧边界和时序。固定值实验最容易发现位对齐、I/Q 顺序和补码错误。

### 实验二：验证复单音方向

发送：

$$
x[n]=Ae^{j2\pi f_bn/F_s}
$$

分别测试 $+f_b$ 和 $-f_b$，观察射频频谱是否位于 LO 两侧的预期位置。

### 实验三：验证滤波器与采样率

使用多个不同频率的复单音扫描基带，记录：

- 通带增益；
- 通带纹波；
- 3 dB 带宽；
- 阻带衰减；
- 镜像和杂散；
- 改变抽取/插值后频响是否仍符合设计。

### 实验四：验证 IQ 失衡

在一个已知频率发送单边带复单音，分别测量目标频点和镜像频点：

$$
IRR=10\log_{10}\left(\frac{P_{desired}}{P_{image}}\right)
$$

改变单音频率后观察 IRR 是否随频率明显变化，可以帮助判断误差更像是增益/相位失衡，还是 I/Q 时延不匹配。

### 实验五：验证数字调制链路

依次使用 BPSK、QPSK、16QAM 等已知星座，检查：

- 星座点位置；
- 星座旋转；
- EVM；
- 脉冲成形；
- 采样率和符号率；
- TX FIR 与 RX FIR 的总群时延。

## 14. 建议的学习路线

### 阶段一：先学懂 IQ

先掌握 [[vault-notes/fpga/ad9361/iq-signals]] 中的正交基、复包络、复数旋转、正负频率、采样率和镜像概念。没有这一步，后面看到 AD9361 的寄存器和滤波链会很容易混乱。

### 阶段二：只看信号链，不看寄存器

能够根据框图回答：

- RF 信号在哪里变成 IQ？
- ADC 位于哪个位置？
- RX 抽取和 TX 插值分别做什么？
- RF PLL 与 BBPLL 各自决定什么？
- 为什么零中频会有 DC 和镜像问题？

### 阶段三：建立速率表

对于任意一个配置，列出：

| 位置 | 采样率/时钟 | 备注 |
| --- | --- | --- |
| FPGA TX 输入 | $F_{BB,TX}$ | FPGA 输出 IQ |
| TX FIR 前后 | 取决于插值配置 | 数字脉冲成形 |
| TX DAC | $F_{DAC}$ | 进入模拟发射链 |
| RX ADC | $F_{ADC}$ | 模拟接收链之后 |
| RX FIR 前后 | 取决于抽取配置 | 输出 FPGA 的 IQ |
| FPGA RX 输出 | $F_{BB,RX}$ | 解调或后续算法 |

### 阶段四：再学习软件驱动

把驱动或 API 的每个配置动作归类到：

- 时钟；
- RF LO；
- 模拟带宽；
- FIR 和采样率；
- 增益；
- 校准；
- 数字接口；
- 状态切换。

这样阅读 Linux IIO、No-OS 或 HDL 工程时，不会被大量寄存器名称淹没。

### 阶段五：最后做硬件级验证

使用示波器、频谱仪或 FPGA 片上逻辑分析仪，逐层确认：SPI → 时钟 → 数字 IQ → 复频谱 → 射频输出/输入 → 调制质量。
