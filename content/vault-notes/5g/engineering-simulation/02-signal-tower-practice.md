# 🗼 5G 工程实践仿真：信号塔

> [!abstract] 本页记录
> 信号塔现场的支撑杆、GPS、RRU、连接头、线缆与机房传输配置。

## 1. 支撑杆

器件选择
GPS : GPS1
RRU :  不需要
连接头 :NJ-1/2
天线 : 不需要
线缆 : 1/2馈线

## 2. 单管塔(2G)

器件选择

GPS : 不需要
RRU : 不需要
连接头 : NJ-7/8
天线 : 2G天线
线缆 : 7/8馈线

## 3. 楼顶美化天线(3G)

器件选择

GPS : 不需要该器件
RRU : 3G RRU
连接头 : **6G**-1310nm-1.4km-SM-SFP+(光纤)
天线 :  3G天线
线缆 : 野战光缆(RRU-BBU),天馈跳线(RRU-天线)


## 4. 三边形角钢塔(4G)

器件选择

GPS : 不需要该器件
RRU :  4G RRU
连接头 : **10G**-1310nm-1.4km-SM-SFP+(光纤)
天线 :  4G天线
线缆 : 野战光缆,天馈跳线

## 5. 仿生树

器件选择

GPS: 不需要该器件
RRU : 5G RRU 
连接头 : **25G**-1310nm-1.4km-SM-SFP+(光纤)
天线 : 不需要该设备(5G RRU与AAU整合在5G AAU上)
线缆 : 野战光缆

### BTS配置

2G - BTS
供电线缆: 10平蓝黑电源线
连接供电设备 : 直流电源柜
光纤通信接头 : 2M线

3G - BBU
供电线缆 : 6平蓝黑电源线
连接供电设备 : 直流电源柜
光纤通信接头: LC-LC
回传光模块: **1.25G**-1310nm-1.4km-SM-SFP+
前传光模块: **6G**-1310nm-1.4km-SM-SFP+

> 备注 : 回传光模块是BBU -> 核心网 ; 前传光模块是 BBU-> UE(RRU)

4G-BBU
供电线缆 : 6平蓝黑电源线
连接供电设备 : 直流电源柜
光纤通信接头: LC-LC
回传光模块: **1.25G**-1310nm-1.4km-SM-SFP+
前传光模块: **10G**-1310nm-1.4km-SM-SFP+

5G-BBU

DCPD配置界面 : 16平蓝黑电源线
连接供电设备 : 直流电源柜

5G BBU 供电线缆: 10平蓝黑电源线
连接供电设备 : DCPD
光纤通信接头 : LC-LC
回传光模块 : **25G**-1310nm-1.4km-SM-SFP+
前传光模块 : **25G**-1310nm-1.4km-SM-SFP+
