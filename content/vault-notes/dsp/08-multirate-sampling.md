## 本章主线

- **输入条件**：前七章都在固定采样率下工作，但实际系统的不同模块工作在不同速率（音频 44.1k↔48k、SDR 的 ADC↔基带）。
- **核心机制**：抽取 = 降采样 + 抗混叠低通；插值 = 升采样 + 抗镜像低通；多相分解把滤波搬到低速率侧。
- **输出结果**：任意有理数倍采样率转换，且运算量降到约 $1/D$ 或 $1/I$——这是让多速率系统在算力上可行的关键。

一句话：**多抽样率的核心是"滤波器 + 采样率变换"，多相分解让这个组合在计算上可行。**

### 记号约定

| 记号 | 含义 |
| --- | --- |
| $D$、$I$ | 抽取因子、插值因子（正整数） |
| $\downarrow D$、$\uparrow I$ | $D$ 倍抽取器、$I$ 倍插值器 |
| $H(z)$ | 抗混叠／抗镜像低通 |
| $L/M$ | 有理数倍转换：$\uparrow L$ → 低通 → $\downarrow M$ |
| 归一化频率 | 以**当前采样率**为基准，抽取/插值后 Nyquist 会变 |

## 1. 为什么需要多抽样率

若所有模块都按最高速率工作，运算量与存储会爆炸。多速率技术让每个模块只在自己需要的速率下运算，代价是必须处理"采样率变化时频谱怎么搬"这个问题。

| 场景 | 速率差异 |
| --- | --- |
| 音频 | 44.1 kHz（CD）↔ 48 kHz ↔ 96 kHz |
| 软件无线电 | ADC 采中频（几十 MHz）→ 基带（几百 kHz） |
| OFDM | 子载波符号率 ↔ FFT 采样率 |
| 滤波器组 | 分析组降采样，综合组升采样 |

## 2. 序列的抽取

### 定义与正确结构

每隔 $D$ 个点取一个，采样率从 $f_s$ 降到 $f_s/D$。但**直接丢点会让高频折回低频**，所以抽取的正确顺序是"先低通到 $\pi/D$，再丢点"。

$$
x_d(n)=x(nD),\qquad n=0,1,2,\dots
$$

丢点本身只改变时间轴，真正的问题在频域：降速率会让频谱被展宽，所以正确的结构是"先低通、后丢点"。

$$
x(n)\to\boxed{H(z)}\to\downarrow D\to x_d(n)
$$

### 频域关系

抽取把原频谱压到 $[-\pi/D,\pi/D]$ 再展宽回 $[-\pi,\pi]$，同时把 $D-1$ 个搬移副本叠加进来。只要原信号带宽超过 $\pi/D$，副本就会重叠成混叠——这就是为什么必须先滤波。

$$
X_d(e^{j\omega})=\frac{1}{D}\sum_{k=0}^{D-1}X\left(e^{j(\omega-2\pi k)/D}\right)
$$

例：$f_s=16$ kHz 含 1 kHz 与 7 kHz，2 倍抽取后新 Nyquist 只有 4 kHz，7 kHz 折到 $8-7=1$ kHz 与原 1 kHz 重合、无法分辨；先低通到 4 kHz 再抽取就只剩干净的 1 kHz。

### 两种实现

| 实现 | 结构 | 运算量 |
| --- | --- | --- |
| 先滤波后抽取 | $H(z)$ 在高速率下运行再丢点 | 大（每点都算） |
| 多相抽取 | 分解成 $D$ 个相位，低速率下算 | 约 $1/D$ |

### 适用前提

- 抗混叠滤波器的截止必须按"抽取后"的 Nyquist 折算，即原采样率下的 $\pi/D$。
- 多相抽取要求 $H(z)$ 长度是 $D$ 的合理倍数（或补零），否则各相长度不等。
- 抽取是可逆的"降速率"操作，但**不可逆于信息**：滤掉的成分回不来。

### 常见工程坑点

- 直接 `x(1:D:end)` 丢掉滤波，得到的频谱混叠在时域看是"信号变糙"，在频域看是"多出一堆不该有的线"。
- 抽取后再按原采样率归一化设计滤波器，截止频率会差 $D$ 倍。

## 3. 序列的插值

### 定义与正确结构

每两个原样点之间插 $I-1$ 个零，采样率升到 $If_s$。插零只是"占位"，频谱会出现 $I$ 个镜像副本，必须用截止 $\pi/I$、增益 $I$ 的低通把它们滤掉，才得到真正平滑的插值。

$$
x_i(n)=\begin{cases}x(n/I),&n=0,\pm I,\pm2I,\dots\\0,&\text{其他}\end{cases}
$$

零值只是占位，真正的插值要靠随后的低通把镜像滤掉并把电平补回来。

$$
x(n)\to\uparrow I\to\boxed{H(z)}\to x_i(n)
$$

### 频域关系

插值把原频谱压缩 $I$ 倍，于是在 $[-\pi,\pi]$ 内出现 $I$ 个副本（镜像）；抗镜像滤波器保留基带那一个、滤掉其余。插零还使平均功率下降 $I$ 倍，所以滤波器增益要乘 $I$ 补偿。

$$
X_i(e^{j\omega})=X(e^{j\omega I})
$$

例：$x=\{1,2,3\}$ 2 倍插零得 $\{1,0,2,0,3,0\}$，频谱压缩一半并在 $\pi$ 附近出现镜像；用截止 $\pi/2$ 的低通滤掉镜像后才是平滑插值。

### 两种实现

| 实现 | 结构 | 运算量 |
| --- | --- | --- |
| 先插零后滤波 | 高速率滤波，大量输入是零 | 大（乘零浪费） |
| 多相插值 | 分解成 $I$ 个相位，低速率下算 | 约 $1/I$ |

### 常见工程坑点

- 只插零不滤波，输出波形是"阶梯 + 高频毛刺"，听感/眼图都会暴露。
- 忘记增益 $I$：插值后整体电平低了 $I$ 倍，看起来像"信号变弱"。

## 4. 抽取与插值的频域分析

### $L/M$ 有理数倍转换

先插 $L$ 倍把速率抬到 $Lf_s$，再低通，最后抽 $M$ 倍降到 $\frac LMf_s$。低通同时承担抗镜像与抗混叠两个职责，截止取 $\min(\pi/L,\pi/M)$。

$$
x(n)\to\uparrow L\to\boxed{H(z)}\to\downarrow M\to y(n)
$$

| 操作 | 时域 | 频域 | 关键滤波器 |
| --- | --- | --- | --- |
| 抽取 | $x_d(n)=x(nD)$ | $\frac1D\sum_{k=0}^{D-1}X(e^{j(\omega-2\pi k)/D})$ | 抗混叠，截止 $\pi/D$ |
| 插值 | 插 $I-1$ 个零 | $X(e^{j\omega I})$ | 抗镜像，截止 $\pi/I$，增益 $I$ |
| $L/M$ | $\uparrow L$→滤→$\downarrow M$ | 压缩 $L$、展宽 $M$ | 截止 $\min(\pi/L,\pi/M)$ |

### 诺贝尔恒等式

它允许把滤波器"搬过"采样率变换器，是高效实现的理论依据：搬过抽取器要换成 $H(z^D)$，搬过插值器要换成 $H(z^I)$。有了它才能把滤波搬到低速率侧。

$$
H(z)\downarrow D\ =\ \downarrow D\,H(z^D);\qquad H(z)\uparrow I\ =\ \uparrow I\,H(z^I)
$$

### 常见工程坑点

- 频率归一化陷阱：同一个物理频率在抽取/插值后对应的 $\omega$ 会变（1 kHz 在 48 kHz 下是 $2\pi\cdot1000/48000$，在 24 kHz 下是其两倍），滤波器必须以**当前采样率**归一化。
- $L/M$ 顺序颠倒（先抽后插）会先丢信息再补零，结果完全是错的。

## 5. 多相分解

### 定义

把滤波器的系数按 $n\bmod D$ 分成 $D$ 组，每组构成一个子滤波器。这样每个子滤波器只在原速率的 $1/D$ 下工作，算量自然降下来。

$$
H(z)=\sum_{k=0}^{D-1}z^{-k}E_k(z^D),\qquad E_k(z)=\sum_{m}h(mD+k)z^{-m}
$$

### 多相抽取器与插值器

抽取时用诺贝尔恒等式把 $E_k(z^D)$ 搬到抽取器之后，每个 $E_k(z)$ 只在抽取时刻计算；插值时把 $E_k(z^I)$ 搬到插值器之前，每个子滤波器只处理低速率输入。两种结构的总乘法数都降到原来的约 $1/D$ 或 $1/I$。

```
抽取：x(n) → [z^-k] → [E_k(z)] → ↓D → y(n)
插值：x(n) → [E_k(z)] → ↑I → y(n)
```

| 实现 | 乘法数（每输出点） |
| --- | --- |
| 直接滤波（高速率） | $N$ |
| 多相抽取 | $N/D$ |
| 多相插值 | $N/I$ |
| $L/M$ 转换 | $N/\max(L,M)$ 量级 |

例：64 阶低通做 8 倍抽取，直接实现每点 64 次乘，多相实现是 8 个 8 阶子滤波器各在 $f_s/8$ 下工作，总乘法降到 1/8。

### 适用前提

- 多相分解要求抽取/插值因子与滤波器长度匹配，否则各相系数长度不等，需补零对齐。
- 诺贝尔恒等式只在"采样率变换是纯抽取/纯插值"时成立，含其他非线性环节时不能随便搬。
- 多相结构要求滤波器是 FIR，IIR 无法这样分相。

### 常见工程坑点

- 多相实现时系数按 $n\bmod D$ 分组写错（写成"每 D 个连续取一段"），结果每个相位都是错的。
- 只降运算量不做增益补偿，插值侧输出电平偏低。

## 6. 典型应用

- **分数倍重采样**：44.1 kHz → 48 kHz 即 $L/M=160/147$；音频变调、图像缩放、视频帧率转换同理。
- **滤波器组**：分析组把信号分成多子带并各自抽取，综合组插值后合成；QMF、离散小波变换都是多速率系统。
- **OFDM 与 SDR**：OFDM 的 IFFT/FFT 本身就是多速率结构（$\Delta f=f_s/N$）；SDR 的 DDC/DUC 走"ADC → 数字混频 → CIC/多相抽取 → 基带"，CIC 不需要乘法器，是抽取/插值的常用高效结构。
- **音频与图像**：重采样、抗混叠；图像金字塔、多分辨率分析。

以下代码覆盖三条最常用的调用：自动带滤波的抽取/插值、有理数倍转换、以及显式的多相实现。注意 `decimate`/`interp` 内部已经含抗混叠/抗镜像滤波器。

```matlab
y  = decimate(x, 4);            % 4 倍抽取（内部 FIR 抗混叠）
y  = interp(x, 4);              % 4 倍插值（内部抗镜像 + 增益补偿）
y  = resample(x, 160, 147);     % 44.1k → 48k（自动选滤波器）
y  = upfirdn(x, h, L, M);       % 先插 L、滤 h、再抽 M（多相实现）
h  = designMultirateFIR(L, M);  % 生成多速率滤波器
dec = dsp.FIRDecimator(4, h);   % 流式处理对象
```
