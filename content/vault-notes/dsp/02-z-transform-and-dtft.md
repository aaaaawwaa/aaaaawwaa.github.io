## 本章主线

- **输入条件**：时域的序列、卷积与差分方程（第 1 章的成果），它们算起来慢且不直观。
- **核心机制**：$z=e^{sT}$ 换坐标系，把序列变成复变量 $z$ 的函数；单位圆截面即 DTFT。
- **输出结果**：卷积变乘法、差分方程变有理函数、稳定性变成"极点在不在单位圆内"。

四节是一条链：**Laplace $\xrightarrow{z=e^{sT}}$ z 变换 $\xrightarrow{|z|=1}$ DTFT $\to$ 频率响应**。

### 记号约定

| 记号 | 含义 | 纪律 |
| --- | --- | --- |
| $z=re^{j\omega}$ | 复变量，$r=|z|$ | $X(z)=\mathcal Z[x(n)]$ |
| ROC | 收敛域 | **凡写 $X(z)$ 必须同时给 ROC**，否则答案不唯一 |
| $X(e^{j\omega})$ | 单位圆上的取值 | 专指 DTFT |
| $H(e^{j\omega})$ | 系统的频率响应 | 专指 LSI 系统 |
| $z^{-1}$ | 代数上是除以 $z$，结构上是**延迟一拍** | 第 5 章结构图的积木 |
| × ／ ○ | 极点 ／ 零点 | 画在 z 平面上 |

## 1. 序列的 z 变换

### 为什么需要它

DTFT 要求 $\sum|x(n)|<\infty$，可 $u(n)$ 与 $|a|>1$ 的 $a^nu(n)$ 都发散。解法是给它乘一个可调的衰减因子 $r^{-n}$，把发散级数"压"收敛；把 $r^{-n}$ 与 $e^{-j\omega n}$ 合并就得到以复数 $z=re^{j\omega}$ 为自变量的函数。所以 z 变换不是新技巧，而是**给 DTFT 加了一个衰减旋钮**，"哪些 $z$ 能收敛"（ROC）因此成为变换不可分割的一部分。

$$
\sum_{n}|x(n)r^{-n}|<\infty\ \text{对某些 }r;\qquad r^{-n}e^{-j\omega n}=z^{-n}
$$

### 双边定义与第一条纪律

$X(z)$ 是把序列投影到一组复指数基上的结果，$z$ 的模负责压序列的增长、辐角负责频率。**但同一个代数式可对应不同序列**，因此序列与 $(X(z),\text{ROC})$ 这一对才一一对应。

$$
X(z)=\sum_{n=-\infty}^{\infty}x(n)z^{-n};\qquad x(n)=\frac{1}{2\pi j}\oint_C X(z)z^{\,n-1}dz
$$

例：$a^nu(n)$ 与 $-a^nu(-n-1)$ 的 $X(z)$ 都是 $\dfrac{1}{1-az^{-1}}$，前者 ROC 在 $|z|>|a|$（右边序列），后者在 $|z|<|a|$（左边序列）。**给 $X(z)$ 不给 ROC，等于没给答案。**

### 单边 z 变换

它只"看见" $n\ge0$ 的部分，因此天然用于"带初始条件的差分方程"。代价是移位性质多出一串初始值项——这是它唯一需要小心的地方。

$$
x(n-m)\leftrightarrow z^{-m}X_1(z)+\sum_{k=1}^{m}x(-k)z^{-(m-k)};\quad x(n-1)\leftrightarrow z^{-1}X_1(z)+x(-1)
$$

三步法解差分方程：两边取单边变换（移位项自动带出 $y(-1),y(-2)$）→ 解代数方程得 $Y_1(z)$（零输入与零状态已合成）→ 反变换。与第 1 章"齐次解 + 特解"相比，这里不用猜特解、不用联立方程。

### 收敛域决定一切

ROC 由 $|z|$ 单变量决定，所以它必然是以原点为中心的环形区域，且**内部不含任何极点**——极点处 $X(z)$ 无界。$n\to+\infty$ 的项由 $z^{-n}$ 压（$z$ 越大越收敛），$n\to-\infty$ 的项由 $z^{-n}$ 压（$z$ 越小越收敛），于是"哪边无限，就往哪边要收敛域"。

| 序列类型 | 定义域 | ROC |
| --- | --- | --- |
| 有限长 | $n_1\le n\le n_2$ | $0<|z|<\infty$（可能挖去 $0$ 或 $\infty$） |
| 右边（因果） | $n\ge n_1$ | $|z|>R_{x-}$（圆外），含 $z=\infty$ |
| 左边（反因果） | $n\le n_2$ | $|z|<R_{x+}$（圆内），含 $z=0$ |
| 双边 | $-\infty<n<\infty$ | $R_{x-}<|z|<R_{x+}$（圆环） |

![[vault-notes/assets/02-z-transform-and-dtft/fig-01.png]]

两条秒杀推论：**因果 ⟺ ROC 是最外层极点之外的圆外区域且含 $\infty$**；**稳定 ⟺ ROC 含单位圆**。两者合起来就是"因果且稳定 ⟺ 极点全在单位圆内"。

### 反 z 变换

三种方法按题目形状选：留数法通用（被积函数是 $X(z)z^{n-1}$，别漏 $z^{n-1}$）；部分分式法适合有理函数求闭式；长除法只取前几项数值。做题第一步永远是**先求极点、画数轴、看 ROC 落在哪一段**。

| 方法 | 做法 | 适用 |
| --- | --- | --- |
| 留数法 | $x(n)=\sum_{C\text{ 内极点}}\mathrm{Res}[X(z)z^{n-1}]$ | 通用，极点多时最快 |
| 部分分式 | 拆成一阶/二阶项查表 | 有理函数 + 要闭式解，考试首选 |
| 长除法 | 展成 $\sum x(n)z^{-n}$ 读系数 | 只要前几项、做校验 |

部分分式的八步流程：清负幂 → 除以 $z$ → 比较次数（必要时长除）→ 分母因式分解 → 写出各项（重根写满）→ 求系数（遮盖法/通分/导数法）→ 乘回 $z$ → 按 ROC 定左右。之所以要先除以 $z$，是因为标准变换对的分子常带一个 $z$，除完才对得上表。

$$
A_{r-k}=\left.\frac{1}{k!}\frac{d^kG(z)}{dz^k}\right|_{z=a},\ G(z)=(z-a)^rF(z)
$$

例：$X(z)=\dfrac{1}{(1-0.5z^{-1})(1-2z^{-1})}$，极点在 $0.5$ 与 $2$，把 $z$ 平面切成三段，对应三个不同序列。

$$
\frac{1}{(1-0.5u)(1-2u)}=\frac{-1/3}{1-0.5u}+\frac{4/3}{1-2u},\qquad u=z^{-1}
$$

| ROC | 极点 0.5 | 极点 2 | $x(n)$ |
| --- | --- | --- | --- |
| $|z|>2$ | 界内→右边 | 界内→右边 | $[-\frac13(0.5)^n+\frac43 2^n]u(n)$ |
| $|z|<0.5$ | 界外→左边 | 界外→左边 | $[\frac13(0.5)^n-\frac43 2^n]u(-n-1)$ |
| $0.5<|z|<2$ | 右边 | 左边 | $-\frac13(0.5)^nu(n)-\frac43 2^nu(-n-1)$ |

只有第三种 ROC 含单位圆，因此**只有它稳定**，而 $X(z)$ 的表达式一字未变。这就是"ROC 决定一切"最生动的例子。

### 性质（表 2-2）

这些性质是"把时域动作翻译成 z 域动作"的词典，其中最值钱的一条是时域卷积变乘法——第 3、4 章（DFT/FFT）的全部动机都是"想办法在有限长上重现这个乘法"。

| 性质 | 序列 | z 变换 | ROC |
| --- | --- | --- | --- |
| 线性 | $ax+by$ | $aX+bY$ | $\supset R_x\cap R_y$ |
| 移位 | $x(n-m)$ | $z^{-m}X(z)$ | $R_x$（$0/\infty$ 可能变） |
| 乘指数 | $a^nx(n)$ | $X(z/a)$ | $|a|R_x$ |
| 翻转 | $x(-n)$ | $X(1/z)$ | $1/R_x$ |
| 共轭 | $x^*(n)$ | $X^*(z^*)$ | $R_x$ |
| 乘 $n$ | $nx(n)$ | $-z\frac{dX}{dz}$ | $R_x$ |
| 时域卷积 | $x*h$ | $X(z)H(z)$ | $\supset R_x\cap R_y$ |
| 序列相乘 | $x\cdot y$ | 复卷积 | 环状 |
| 部分和 | $\sum_{k\le n}x(k)$ | $X(z)/(1-z^{-1})$ | $+|z|>1$ |
| 初值（因果） | $x(0)$ | $\lim_{z\to\infty}X(z)$ | — |
| 终值 | $x(\infty)$ | $\lim_{z\to1}(1-z^{-1})X(z)$ | 极点在圆内（$z=1$ 允许一阶） |

三条最常用各自的工程动作：**卷积定理**（时域最麻烦的运算在 z 域是最简单的乘法）；**乘指数**（$a^nx(n)\leftrightarrow X(z/a)$，通带搬移、调制、变频全靠它）；**乘 $n$**（斜坡响应与重复极点）。

### 常用变换对（表 2-1）

右列 ROC 与左列序列一一绑定，必须成对背，否则反变换时必然分不清左右序列。

| $x(n)$ | $X(z)$ | ROC |
| --- | --- | --- |
| $\delta(n)$ | $1$ | 全平面 |
| $\delta(n-m),m>0$ | $z^{-m}$ | $z\ne0$ |
| $u(n)$ | $1/(1-z^{-1})$ | $|z|>1$ |
| $-u(-n-1)$ | $1/(1-z^{-1})$ | $|z|<1$ |
| $a^nu(n)$ | $1/(1-az^{-1})$ | $|z|>|a|$ |
| $-a^nu(-n-1)$ | $1/(1-az^{-1})$ | $|z|<|a|$ |
| $na^nu(n)$ | $az^{-1}/(1-az^{-1})^2$ | $|z|>|a|$ |
| $R_N(n)$ | $(1-z^{-N})/(1-z^{-1})$ | $|z|>0$ |
| $e^{j\omega_0n}u(n)$ | $1/(1-e^{j\omega_0}z^{-1})$ | $|z|>1$ |
| $\cos\omega_0n\,u(n)$ | $\dfrac{1-\cos\omega_0z^{-1}}{1-2\cos\omega_0z^{-1}+z^{-2}}$ | $|z|>1$ |
| $\sin\omega_0n\,u(n)$ | $\dfrac{\sin\omega_0z^{-1}}{1-2\cos\omega_0z^{-1}+z^{-2}}$ | $|z|>1$ |
| $a^n\cos\omega_0n\,u(n)$ | $\dfrac{1-a\cos\omega_0z^{-1}}{1-2a\cos\omega_0z^{-1}+a^2z^{-2}}$ | $|z|>|a|$ |
| $a^n\sin\omega_0n\,u(n)$ | $\dfrac{a\sin\omega_0z^{-1}}{1-2a\cos\omega_0z^{-1}+a^2z^{-2}}$ | $|z|>|a|$ |

### 适用前提

- 部分分式法要求 $X(z)$ 是**有理函数**，且必须给定 ROC；同一有理式在不同 ROC 下对应不同时域序列。
- 单边变换的收敛域必是某圆外区域，因此反变换统一取右边序列。
- 初值/终值定理只在因果（或极点位置满足条件）时成立，终值定理还要求极点全在单位圆内（$z=1$ 允许一阶）。

### 常见工程坑点

- 忘记先除以 $z$ 或忘记清负幂，分式就与表 2-1 对不上。
- 重极点只写一个分式，漏掉 $A_2/(z-a)^2$ 等高阶项，通分比较时系数全错。
- 假分式（分子次数 ≥ 分母）不做长除，结果里会漏掉 $\delta(n)$ 及其移位项。除 $z$ 后若多出 $z=0$ 极点，乘回 $z$ 会留下常数项，对应 $\delta(n)$——它不是笔误。
- 移位性质的 ROC 会变：$x(n-m)\leftrightarrow z^{-m}X(z)$ 在 $m>0$ 时于 $z=0$ 引入极点，ROC 可能失去 $z=0$（$\delta(n)$ 的 ROC 是全平面，$\delta(n-1)$ 则是 $z\ne0$）。

下面这段代码用 `residuez` 一次做完全部分式展开，并反算校验系数。它相当于把手算流程压缩成两行，适合验算而不适合代替推导。

```matlab
% 用 residuez 做部分分式：极点与留数直接可读，能反算回原式
b = 1;  a = [1 -2.5 1];          % (1-0.5z^-1)(1-2z^-1) 展开
[r, p, k] = residuez(b, a)       % p = {0.5, 2}，r 即标准变换对系数
[b2, a2] = residuez(r, p, k);    % 反算校验
norm(b-b2) + norm(a-a2)          % ≈ 0
```

## 2. s 平面与 z 平面的映射

### 映射的来历

抽样信号的 Laplace 变换把 $\delta(t-nT)$ 的积分直接压成求和，再把 $e^{-snT}$ 记成 $(e^{sT})^{-n}$，就得到 $z=e^{sT}$。这一行同时说明三件事：z 变换就是抽样信号的 Laplace 变换；$T$ 藏在这个换元里；DTFT 是它在单位圆上的截面。

$$
\hat X_a(s)=\sum_n x(n)(e^{sT})^{-n}=X(z)\Big|_{z=e^{sT}}
$$

### 极坐标分解与六条对应

把 $s=\sigma+j\Omega$ 代入即得 $|z|=e^{\sigma T}$、$\angle z=\Omega T$，于是**实部管模值、虚部管角度**——这解释了为什么连续系统的左半平面判据到了离散域就变成单位圆。

$$
z=e^{(\sigma+j\Omega)T}\Rightarrow |z|=e^{\sigma T},\ \angle z=\Omega T=\omega
$$

| $s$ 平面 | $z$ 平面 | 含义 |
| --- | --- | --- |
| 虚轴 $\sigma=0$ | 单位圆 $|z|=1$ | 等幅振荡 ↔ 纯正弦 |
| 左半平面 $\sigma<0$ | 圆内 $|z|<1$ | 衰减 ↔ **稳定** |
| 右半平面 $\sigma>0$ | 圆外 $|z|>1$ | 增长 ↔ **不稳定** |
| 原点 $s=0$ | $z=1$ | 直流 |
| $\Omega=\pm\pi/T$ | $z=-1$ | **折叠频率**（奈奎斯特） |

一句话：**s 平面的竖直线（等 $\sigma$）映成 z 平面的圆，横线（等 $\Omega$）映成射线。**

*（图片未随站点发布：s_plane_z_plane_aliasing_interactive 1.html）*

### 多值性 = 混叠

$\angle z=\Omega T$ 只由 $\Omega \bmod 2\pi/T$ 决定，所以 $s$ 平面上宽 $2\pi/T$ 的一整条横带都映成同一张 z 平面。$\Omega$ 从 $-\infty$ 到 $+\infty$，$z$ 就在单位圆上一圈圈地绕——**混叠就是映射不单值**，抗混叠就是"把信号限制在一条带内"。

$$
\Omega\ \text{与}\ \Omega+k\Omega_s\ \Rightarrow\ \text{同一个 }z
$$

### 稳定性判据的迁移

$H(z)$ 的每个极点 $z_p=re^{j\theta}$ 贡献一个模态 $r^n$：$r<1$ 衰减即绝对可和，$r>1$ 发散。于是"$\sum|h(n)|<\infty$"这个分析判据升级成"看极点模值"这个几何判据。

| 系统 | 连续（$H(s)$） | 离散（$H(z)$） |
| --- | --- | --- |
| 稳定 | 极点全在左半平面 | 极点全在单位圆内 |
| 临界 | 极点在虚轴（单阶） | 极点在单位圆上（单阶） |
| 不稳定 | 有极点在右半平面 | 有极点在单位圆外 |
| 稳定 + 因果 | $\mathrm{Re}(s_p)<0$，ROC 含虚轴 | $|z_p|<1$，ROC 含单位圆 |

### 双线性变换（第 6 章预告）

$z=e^{sT}$ 的缺点是多值（会混叠）。工程上设计 IIR 常用双线性变换，把整个 $j\Omega$ 轴单值映到单位圆（不混叠），代价是频率非线性畸变，需要预畸变校正。**"不混叠"与"频率线性"不可兼得**，这是第 6 章两种设计法之争的数学根源。

$$
s=\frac{2}{T}\frac{z-1}{z+1}\iff z=\frac{1+sT/2}{1-sT/2},\qquad \Omega=\frac{2}{T}\tan\frac{\omega}{2}
$$

### 适用前提

- 映射 $z=e^{sT}$ 的前提是**等间隔抽样**；非均匀采样不满足。
- 稳定性对照表要求 ROC 一并给出，否则"极点位置"只能说明模态形状，不能判整个系统。

### 常见工程坑点

- 只看极点不看 ROC：$|a|>1$ 的左边序列 $h(n)=-a^nu(-n-1)$ 极点在外，但它**是稳定的**。
- 把"极点在单位圆上"当成"必不稳定"：累加器极点在 $z=1$，$h(n)=u(n)$ 有界，但不是 BIBO 稳定（阶跃输入线性增长）。"有界"与"BIBO 稳定"要分开说。

## 3. 离散时间傅里叶变换（DTFT）

### 定义与存在条件

DTFT 就是把 $z$ 按在单位圆上取值的 z 变换，得到"离散序列 ↔ 连续频谱"的一对变换。$X(e^{j\omega})$ 是 $\omega$ 的连续、以 $2\pi$ 为周期的复函数——周期来自单位圆绕一圈回到原处。

$$
X(e^{j\omega})=\sum_{n}x(n)e^{-j\omega n};\qquad x(n)=\frac{1}{2\pi}\int_{-\pi}^{\pi}X(e^{j\omega})e^{j\omega n}d\omega
$$

| 条件 | 序列类型 | 频谱形态 |
| --- | --- | --- |
| $\sum|x(n)|<\infty$ | 绝对可和 | 连续函数、一致收敛 |
| $\sum|x(n)|^2<\infty$ | 能量序列 | 均方收敛（个别点可发散） |
| 周期/常数 | 功率序列 | 必须**带冲激**（谱线） |

### 与 z 变换的关系

$X(e^{j\omega})=X(z)|_{z=e^{j\omega}}$ 说明 DTFT 是 z 变换在单位圆上的截面。于是"DTFT 是否存在"等价于"单位圆是否落在 ROC 内"，也就是"极点是否在单位圆内"。

$$
X(e^{j\omega})=X(z)\Big|_{z=e^{j\omega}};\qquad \text{单位圆}\subset\text{ROC}\iff \sum|x(n)|<\infty
$$

### 常用 DTFT 对

最值得研究的是矩形窗的谱：它的主瓣宽 $4\pi/N$、旁瓣约 $-13$ dB，是"最锋利也最脏"的窗。第 3 章的泄漏、第 7 章的窗函数法全部由它派生。

| $x(n)$ | $X(e^{j\omega})$ | 备注 |
| --- | --- | --- |
| $\delta(n)$ | $1$ | 全频带等幅 |
| $\delta(n-n_0)$ | $e^{-j\omega n_0}$ | 纯线性相位 |
| $1$ | $2\pi\sum_k\delta(\omega-2\pi k)$ | 直流谱线 |
| $e^{j\omega_0n}$ | $2\pi\sum_k\delta(\omega-\omega_0-2\pi k)$ | 谱线 |
| $\cos\omega_0n$ | $\pi\sum_k[\delta(\omega-\omega_0-2\pi k)+\delta(\omega+\omega_0-2\pi k)]$ | 一对谱线 |
| $u(n)$ | $1/(1-e^{-j\omega})+\pi\sum_k\delta(\omega-2\pi k)$ | 通带 + 直流冲激 |
| $R_N(n)$ | $e^{-j\omega(N-1)/2}\dfrac{\sin(\omega N/2)}{\sin(\omega/2)}$ | Dirichlet 核，主瓣 $4\pi/N$ |
| $a^nu(n),|a|<1$ | $1/(1-ae^{-j\omega})$ | 一阶低通原型 |

### 性质

两条"对偶"最漂亮：时域卷积 ↔ 频域相乘，时域相乘（加窗）↔ 频域卷积（平滑／泄漏）。DFT 就是这条对称加上"时域周期延拓 + 频域采样"，FFT 只是它的快速算法。

| 性质 | 序列 | DTFT |
| --- | --- | --- |
| 时移 | $x(n-n_0)$ | $e^{-j\omega n_0}X$ |
| 频移（调制） | $e^{j\omega_0n}x(n)$ | $X(e^{j(\omega-\omega_0)})$ |
| 翻转 | $x(-n)$ | $X(e^{-j\omega})$ |
| 共轭 | $x^*(n)$ | $X^*(e^{-j\omega})$ |
| 乘 $n$ | $nx(n)$ | $j\,dX/d\omega$ |
| 时域卷积 | $x*y$ | $XY$ |
| 频域卷积 | $x\cdot y$ | $\frac{1}{2\pi}\int_{-\pi}^{\pi}X(e^{j\theta})Y(e^{j(\omega-\theta)})d\theta$ |
| 帕塞瓦尔 | $\sum|x(n)|^2$ | $\frac{1}{2\pi}\int_{-\pi}^{\pi}|X|^2d\omega$ |

### 共轭对称与实序列频谱

时域共轭会同时带来频域共轭与翻频，时域翻转只带来频域翻转——把 $x^*(n)$ 写成 $X^*(e^{j\omega})$ 是最常见的错。实序列则 $X(e^{j\omega})=X^*(e^{-j\omega})$，于是幅频必偶、相频必奇，**只需算半条频率轴**（`freqz`、`fft` 的实输入都只画一半就是这条）。

$$
x(n)=x_e(n)+x_o(n),\quad x_e=\frac{1}{2}[x+x^*(-n)],\quad x_o=\frac{1}{2}[x-x^*(-n)]
$$

| 序列 / 量 | 对称性 |
| --- | --- |
| 实序列 | $X(e^{j\omega})=X^*(e^{-j\omega})$ |
| 实部 / 虚部 | 偶 / 奇 |
| 幅度 / 相位 | 偶 / 奇（模 $2\pi$） |
| 实偶序列 | $X$ 实且偶 |
| 实奇序列 | $X$ 纯虚且奇 |

### 帕塞瓦尔与能量谱

时域能量等于频域能量，且能量谱密度只由幅频决定、与相位无关。多径只改相位时能量守恒，而均衡器"补相位"不消耗能量——这也是它最容易数值不稳的原因。

$$
\sum_n|x(n)|^2=\frac{1}{2\pi}\int_{-\pi}^{\pi}|X(e^{j\omega})|^2d\omega,\qquad S_{xx}=|X|^2
$$

### 适用前提

- 三种存在条件对应三类序列，做题前必须先判序列类型。
- 帕塞瓦尔与能量谱只对能量序列成立；随机信号要换成功率谱密度（维纳–辛钦）。
- 共轭对称表中的"实序列"结论对复序列不成立。

### 常见工程坑点

- $\dfrac{\sin(\omega N/2)}{\sin(\omega/2)}$ 在 $\omega=0$ 是 $0/0$，极限为 $N$，代码里必须单独处理，否则 `NaN` 会污染整条曲线（频谱图"突然断掉"的典型原因）。
- 相频直接 `angle` 求差分会得到假尖峰，必须先 `unwrap`。

```matlab
% 矩形窗 DTFT 与 Dirichlet 核对照；并验证实序列频谱只需存一半
N = 8; n = 0:N-1; x = ones(1,N); w = linspace(-pi,pi,1024);
X_ana = exp(-1j*w*(N-1)/2).*sin(w*N/2)./sin(w/2);
X_ana(abs(sin(w/2))<1e-12) = N;              % ω=0 取极限
max(abs((x*exp(-1j*n'*w)) - X_ana))           % ≈1e-13
X = fft(randn(1,20)); max(abs(X(1:10)-conj(fliplr(X(12:end)))))   % ≈0
```

## 4. 离散 LSI 系统的频域表征

### 复指数是特征函数

把 $e^{j\omega n}$ 送进 LSI 系统，求和里能提出来的因子恰好与 $n$ 无关，于是输出仍是同一个复指数、只被一个复常数乘了一下。这一句是整个频域分析的地基：**正弦进、正弦出、频率不变**；反过来说，输出里出现输入没有的频率，系统必定非线性（工程上用双音测试看互调）。

$$
y(n)=e^{j\omega n}\sum_m h(m)e^{-j\omega m}\triangleq H(e^{j\omega})e^{j\omega n}
$$

### 系统函数 $H(z)$

零状态条件下输出与输入的 z 变换之比，就是冲激响应的 z 变换，因此 $h(n)$ 与 $(H(z),\text{ROC})$ 一一对应。由差分方程直读 $H(z)$ 是最常用的动作：系数直接抄。

$$
H(z)=\frac{\sum_{r=0}^{M}b_rz^{-r}}{\sum_{k=0}^{N}a_kz^{-k}}=\frac{b_0\prod(1-c_rz^{-1})}{a_0\prod(1-d_kz^{-1})}
$$

$c_r$ 为零点、$d_k$ 为极点；若 $M>N$，$z=0$ 处还会多出 $M-N$ 个零点。四种语言的分工：$h(n)$ 判因果稳定、$H(z)$ 找极点解方程、$H(e^{j\omega})$ 看通带算群延迟、差分方程写代码画结构。

### 幅频、相频、群延迟

幅频决定通带与增益，相频决定失真，群延迟决定**包络**的实际延迟——通信里眼图好坏主要看群延迟是否恒定，因为不同频率到达时间不同就是码间串扰。

$$
H(e^{j\omega})=|H(e^{j\omega})|e^{j\varphi(\omega)};\qquad \tau_g(\omega)=-\frac{d\varphi}{d\omega}
$$

| 量 | 定义 | 工程意义 |
| --- | --- | --- |
| 幅频 | $|H|$（常画 $20\log_{10}|H|$） | 通带/阻带、增益 |
| 相频 | $\arg H$（需 `unwrap`） | 相位失真、时延 |
| 群延迟 | $-d\varphi/d\omega$（单位：样点） | 窄带包络的真实延迟 |

一阶系统 $H=1/(1-az^{-1})$ 的群延迟为 $\tau_g=\dfrac{a\cos\omega-a^2}{1-2a\cos\omega+a^2}$，直流处 $\tau_g(0)=a/(1-a)$（$a=0.9$ 时是 9 个样点）。**$a\to1$ 时群延迟 $\to\infty$：窄带滤波器的"反应慢"是数学必然，不是实现问题。**

### 因果与稳定的 z 域判据

时域判据需要求和，z 域判据只看极点位置，因此做题只画一张极点图就够了。

| 性质 | 时域 | z 域 |
| --- | --- | --- |
| 因果 | $h(n)=0,\ n<0$ | ROC 在最外层极点外且含 $\infty$ |
| 稳定 | $\sum|h(n)|<\infty$ | ROC 含单位圆 |
| 因果 + 稳定 | 两者同时 | **全部极点在单位圆内**，ROC 取 $|z|>\max|d_k|$ |

| 极点位置 | $h(n)$ 模态 | 系统 |
| --- | --- | --- |
| $|d|<1$ 实 | $d^n$ 单调衰减 | 稳定，一/二阶低通高通 |
| $|d|<1$ 复 | $r^n\cos(\theta n+\phi)$ 衰减振荡 | 稳定，谐振/带通 |
| $|d|=1$ | 等幅或线性增长 | 临界（$d=1$ 累加器） |
| $|d|>1$ | 发散 | 不稳定 |

### 零极点矢量法

把 $H(e^{j\omega})$ 看成"各零点/极点指向单位圆工作点的矢量"之比：分子是零点矢量长度积，分母是极点矢量长度积，相位是矢量辐角之差。于是频率响应的形状可以"看图说话"——工作点靠近零点则幅频凹陷，靠近极点则突起。

$$
|H(e^{j\omega})|=|A|\frac{\prod_r|\vec q_r|}{\prod_k|\vec p_k|},\qquad \arg H=\arg A+\sum_r\arg\vec q_r-\sum_k\arg\vec p_k
$$

*（图片未随站点发布：零极点判断滤波器方法.html）*

两条看图法则：零点恰在单位圆上则该频率处 $|H|=0$（陷波器，滤 50 Hz 工频）；极点越靠近单位圆峰越尖、$Q$ 越高、群延迟越大。总纲是"离哪个最近，就最像被哪个主导"。

### 典型一阶、二阶系统

一阶 $H=1/(1-az^{-1})$：$0<a<1$ 直流增益最大即**低通**，$-1<a<0$ 反转即**高通**，$a=0$ 全通无记忆。$a=0.9$ 时两端相差约 25.6 dB——一个极点只能做到这么陡。

$$
|H(e^{j0})|=\frac{1}{1-a},\qquad |H(e^{j\pi})|=\frac{1}{1+a}
$$

一阶差分 $H=1-bz^{-1}$：零点在 $z=b$，$0<b<1$ 时高频相对抬升，即**预加重**；接收端用 $1/(1-bz^{-1})$ 压回来，净效果是把高频信噪比抬上去（调频广播、语音编码都这么做）。

$$
H(z)=1-bz^{-1};\qquad H(z)=1-z^{-1}\ (\text{去直流})
$$

二阶谐振器 $H=\dfrac{1}{1-2r\cos\theta z^{-1}+r^2z^{-2}}$：共轭极点在 $re^{\pm j\theta}$，峰值在 $\omega\approx\theta$ 附近，3 dB 带宽约 $2(1-r)$，$Q\approx\theta/[2(1-r)]$。$r$ 太接近 1 时定点实现的舍入误差会让它自激或产生极限环——FPGA/DSP 上做窄带滤波最常踩的坑。

### 全通与最小相位

全通系统幅频恒为 1、只改相位，专用于相位均衡（把非线性相位拉平、合成 90° 相移网络）。最小相位系统的零点也在单位圆内，三条好处：逆系统因果稳定、能量最集中在 $n=0$ 附近、相位滞后最小。

$$
H_{ap}(z)=\frac{z^{-1}-a}{1-az^{-1}},\ |a|<1;\qquad H(z)=H_{\min}(z)H_{ap}(z)
$$

后者就是通信里信道均衡的标准分解：幅频归最小相位部分，多余相位归全通部分。

### 适用前提

- 特征函数结论要求系统是 LSI；时变或非线性系统不能只用一个 $H(e^{j\omega})$ 描述。
- $H(z)=Y(z)/X(z)$ 必须在**零状态**下取，否则混入零输入响应。
- 零极点矢量法要求 $H$ 已写成因式分解形式（极零点必须先解出来）。

### 常见工程坑点

- "极点全在单位圆内"只是"因果 + 稳定"的判据；单说稳定只看 ROC 含不含单位圆。
- 极点在单位圆上不必然不稳定，零点在单位圆上不影响稳定性（只造成陷波）。
- 谐振峰并不严格在 $\omega=\theta$，会略偏；$\theta$ 靠近 $0$ 或 $\pi$ 时偏移明显到不能用 $\theta$ 近似，工程上靠 `freqz` 数值扫描确认。
- 画 dB 而不是线性幅度：0.9 与 1.0 在线性图上看不见，在 dB 上是 0.9 dB。

下列代码把本节四个结论各验一遍：群延迟等于 $a/(1-a)$、直流增益、谐振峰位置、全通幅频恒为 1。它是把"看图说话"变成数字的唯一手段。

```matlab
% 一阶系统的三个指标 + 二阶谐振器 + 全通校验
b = 1; a = [1 -0.9]; [H,w] = freqz(b,a,512);
gd = -gradient(unwrap(angle(H)), w);  gd(1)        % ≈9 = a/(1−a)
20*log10(abs(H(1)))                                % ≈20 dB
r = 0.95; th = pi/4; [H2,w2] = freqz(1,[1 -2*r*cos(th) r^2],2048);
[~,i] = max(abs(H2)); w2(i)/pi                     % 峰值 ≈ θ/π
max(abs(abs(freqz([-0.5 1],[1 -0.5],512)) - 1))    % 全通 ≈1e-16
```

## 5. LSI 性质判定总结

四条性质互不包含：**LSI 只等于"线性 + 移不变"**，不含因果与稳定。工程上的"可实现"才额外要求因果 + 稳定；LSI 只保证"系统能被 $h(n)$ 与卷积完全描述"。

| 性质 | 定义 | 一句话检验 |
| --- | --- | --- |
| 线性 | $T[ax_1+bx_2]=aT[x_1]+bT[x_2]$ | $x$ 只能一次幂、无常数项 |
| 移不变 | $T[x(n-n_0)]=y(n-n_0)$ | 输出里没有显式 $n$ |
| 因果 | 只看当前与过去 | $h(n)=0,\ n<0$ |
| 稳定 | 有界入→有界出 | $\sum|h(n)|<\infty$ |

| 反例 | 缺哪条 |
| --- | --- |
| $y=x^2(n)$ | 移不变但非线性 |
| $y=x(-n)$ | 线性但非移不变 |
| 累加器 $h=u(n)$ | 因果但不稳定 |
| $|a|>1$ 的 $a^nu(n)$ | 不稳定但因果 |

| 已知条件 | 最省事的路径 |
| --- | --- |
| $h(n)$ | 看 $h(n)=0\,(n<0)$ 与 $\sum|h(n)|$ |
| 差分方程 | 先写 $H(z)$ 定极点与 ROC，再反求 $h(n)$ 校验 |
| $H(z)$ 表达式 | **必须配 ROC**；ROC 判左右与稳定，极点判形状 |
| 零极点图 | 圆内/圆上/圆外 → 衰减/临界/发散；零点只影响凹陷 |
| 结构图 | 有无反馈、有无未来支路、系数是否随 $n$ 变 |

推荐流程：先判线性与移不变（确认能否用卷积）→ 差分方程写 $H(z)$、因式分解得极点 → **先定 ROC** 再判稳定 → 反求 $h(n)$ 用绝对可和与极点位置互相校验。

### 常见工程坑点

- 只看 $H(z)$ 表达式判因果：$a^nu(n)$ 与 $-a^nu(-n-1)$ 的 $H(z)$ 完全相同，必须靠 ROC 区分。
- 把 $z=\infty$ 在不在 ROC（因果）与单位圆在不在 ROC（稳定）混用。
- 把反馈当成非因果：$y=ay(n-1)+x(n)$ 有反馈但仍因果，因为它只用过去。
