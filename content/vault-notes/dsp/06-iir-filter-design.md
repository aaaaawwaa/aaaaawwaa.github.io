## 本章主线

- **输入条件**：只有一组指标——通带/阻带边沿、通带波纹、阻带衰减，没有 $H(z)$。
- **核心机制**：借模拟滤波器的成熟公式得到 $H_a(s)$，再用 $s\to z$ 映射搬进数字域。
- **输出结果**：满足指标的因果稳定 $H(z)$，阶数尽量低；映射方式决定"混叠"与"频率畸变"二选一。

一句话：**IIR 设计 = 借模拟之壳、生数字之蛋。** 两种映射的本质差别只有一条：**脉冲响应不变法保频率刻度但会混叠，双线性变换法不混叠但频率刻度被压弯（需预畸变）。**

### 记号约定

| 记号 | 含义 |
| --- | --- |
| $\Omega$、$\omega$ | 模拟角频率（rad/s）、数字角频率（rad），$\omega=2\pi f/f_s$ |
| $\Omega_p/\omega_p$、$\Omega_s/\omega_s$ | 通带边沿、阻带边沿 |
| $\alpha_p$、$\alpha_s$ | 通带最大衰减、阻带最小衰减（dB） |
| $\Omega_c$、$N$ | 截止（3 dB）频率、阶数 |
| $H_a(s)$、$H(z)$ | 模拟、数字滤波器 |
| 双线性变换 | $s=\frac2T\frac{1-z^{-1}}{1+z^{-1}}$，常取 $T=1$ 归一化 |
| 预畸变 | $\Omega=\frac2T\tan\frac{\omega}{2}$ |

## 1. 设计流程与为什么绕道模拟域

数字指标先经预畸变换成模拟指标，再选原型求阶数、写出 $H_a(s)$，最后映射成 $H(z)$ 并用第 5 章的结构实现。绕道模拟域不是因为数字域做不了，而是因为模拟滤波器有一整套闭式公式与表格可以直接继承。

```
数字指标(ω_p, ω_s, α_p, α_s)
   → 预畸变 → 模拟指标(Ω_p, Ω_s, α_p, α_s)
   → 选原型 + 求 N、Ω_c → H_a(s)
   → s→z 映射（脉冲响应不变 / 双线性）→ H(z)
   → 选结构（直接型/级联/并联）→ 实现
```

| 绕道原因 | 说明 |
| --- | --- |
| 闭式公式 | 巴特沃斯、切比雪夫、椭圆都有成熟的 $H_a(s)$ 与阶数估计式 |
| 工具成熟 | MATLAB 的 `buttap`/`cheb1ap`/`ellipap` 直接给原型 |
| 指标直观 | 通带波纹、阻带衰减在模拟域有标准表格 |
| 映射理论完整 | 两种经典映射的性质与适用条件都已清楚 |

## 2. 指标定义与映射要求

指标只约束幅频：通带内衰减不超过 $\alpha_p$、阻带内衰减不低于 $\alpha_s$，两者之间的过渡带越窄、所需阶数越高。用 dB 表述时，衰减就是幅频倒数的对数量。

$$
\alpha_p=-20\log_{10}\left|H(e^{j\omega_p})\right|,\qquad \alpha_s=-20\log_{10}\left|H(e^{j\omega_s})\right|
$$

| 指标 | 含义 | 典型值 |
| --- | --- | --- |
| 通带边沿 $\omega_p$ | 幅频下降不超过 $\alpha_p$ | $0.2\pi$ |
| 阻带边沿 $\omega_s$ | 衰减不低于 $\alpha_s$ | $0.3\pi$ |
| 通带波纹 $\alpha_p$ | 通带内最大衰减 | 1 dB / 3 dB |
| 阻带衰减 $\alpha_s$ | 阻带最小衰减 | 40 dB / 60 dB |

映射 $s\to z$ 必须做到四件事：虚轴映到单位圆（频率轴对频率轴）、左半平面映到单位圆内（稳定保持）、因果性保持、通带阻带的相对关系保持。两条经典映射在"混叠"上分道扬镳。

| 方法 | 映射 | 频率关系 | 混叠 |
| --- | --- | --- | --- |
| 脉冲响应不变法 | $z=e^{sT}$ | $\omega=\Omega T$（线性） | 有 |
| 双线性变换法 | $s=\frac2T\frac{1-z^{-1}}{1+z^{-1}}$ | $\Omega=\frac2T\tan\frac{\omega}{2}$（非线性） | 无 |

## 3. 模拟原型

### 巴特沃斯

幅平方在原点最平坦、在截止处衰减 3 dB，通带无波纹、阻带单调下降——牺牲陡度换相位与平坦度。$N$ 越大过渡带越陡，但相位非线性越严重，极点均匀分布在 $s$ 平面半径 $\Omega_c$ 的圆上（取左半平面）。

$$
\left|H_a(j\Omega)\right|^2=\frac{1}{1+\left(\Omega/\Omega_c\right)^{2N}}
$$

阶数由"通带衰减、阻带衰减、两个边沿的比值"共同决定，取满足条件的最小整数：

$$
N\ge\frac{\log_{10}\left[\dfrac{10^{\alpha_s/10}-1}{10^{\alpha_p/10}-1}\right]}{2\log_{10}\left(\dfrac{\Omega_s}{\Omega_p}\right)}
$$

### 切比雪夫

把波纹集中到通带（I 型）或阻带（II 型），用同样的阶数换更陡的过渡带。$\varepsilon$ 由通带波纹唯一确定：$\varepsilon=\sqrt{10^{\alpha_p/10}-1}$。

$$
\left|H_a(j\Omega)\right|^2=\frac{1}{1+\varepsilon^2T_N^2\left(\Omega/\Omega_p\right)}
$$

### 椭圆与贝塞尔

椭圆滤波器在通带与阻带都等波纹，相同阶数下过渡带最陡，代价是相位非线性最严重。贝塞尔滤波器相反：过渡带最缓，但通带内相位近似线性，适合"保波形"的场合。

| 类型 | 通带 | 阻带 | 过渡带陡度 | 相位线性 |
| --- | --- | --- | --- | --- |
| 巴特沃斯 | 平坦 | 单调 | 最缓 | 好 |
| 切比雪夫 I | 等波纹 | 单调 | 较陡 | 较差 |
| 切比雪夫 II | 单调 | 等波纹 | 较陡 | 较差 |
| 椭圆 | 等波纹 | 等波纹 | **最陡** | 最差 |
| 贝塞尔 | 平坦 | 单调 | 最缓 | **最好** |

选型口诀：要平坦选巴特沃斯，要陡选椭圆，要相位选贝塞尔，折中选切比雪夫。

### 适用前提

- 阶数公式要求 $\Omega_s>\Omega_p$、$\alpha_s>\alpha_p$，低通原型才有解。
- 原型都按归一化截止（$\Omega_c=1$）给出，用前要做频率缩放。
- 波纹类原型的指标是"保证值"，实际衰减会略优于指标。

## 4. 脉冲响应不变法

### 思想与映射

让数字滤波器的冲激响应等于模拟冲激响应的等间隔采样，于是极点按 $z=e^{sT}$ 一一对应：左半平面映到单位圆内、虚轴映到单位圆，频率刻度保持线性 $\omega=\Omega T$。

$$
h(n)=Th_a(nT);\qquad z_k=e^{s_kT}
$$

例：$H_a(s)=\dfrac{a}{s+a}$ 的 $h_a(t)=ae^{-at}u(t)$，采样后取 z 变换得 $H(z)=\dfrac{Ta}{1-e^{-aT}z^{-1}}$，极点 $s=-a$ 映到 $z=e^{-aT}$（在圆内）。$aT\ll1$ 时低频段与模拟滤波器一致。

$$
H(z)=\frac{Ta}{1-e^{-aT}z^{-1}}
$$

### 混叠

采样使频响变成模拟频响的周期延拓，于是 $\Omega>\pi/T$ 的成分会折回通带。低通因高频衰减大而混叠小，高通因高频增益大而不适用。

$$
H(e^{j\omega})=\frac1T\sum_{k=-\infty}^{\infty}H_a\!\left(j\frac{\omega-2\pi k}{T}\right)
$$

| 类型 | 混叠影响 | 是否适用 |
| --- | --- | --- |
| 低通 | 高频衰减大，混叠小 | 适用 |
| 带通 | 高频衰减够时混叠小 | 可用 |
| 高通 | 高频增益大，严重混叠 | 不适用 |
| 带阻 | 高频/低频都可能混叠 | 慎用 |

### 常见工程坑点

- 混叠不可消除，只能靠加大阻带衰减或提高采样率压制；阻带指标不够时高频会悄悄折回通带。
- $T$ 不能省：$h(n)=Th_a(nT)$ 中的 $T$ 决定直流增益，漏掉会差 $1/T$；MATLAB `impinvar` 默认 $T=1$，要自行核对增益。

## 5. 双线性变换法

### 思想与映射

用一个分式代换把整个 $j\Omega$ 轴压到单位圆上，于是不存在周期重复，也就没有混叠。代价是频率轴被"压弯"：$\omega$ 从 0 到 $\pi$ 时 $\Omega$ 从 0 到 $\infty$。

$$
s=\frac2T\frac{1-z^{-1}}{1+z^{-1}}\iff z=\frac{1+(T/2)s}{1-(T/2)s}
$$

它是 $s$ 平面到 $z$ 平面的一一映射：左半平面仍映到圆内（稳定保持），虚轴仍映到单位圆（频率轴保持），但刻度变成非线性。

### 频率畸变与预畸变

因为映射非线性，数字边沿直接换算成模拟边沿会偏，必须先按同一个非线性关系"反向"把数字边沿预畸变成模拟边沿。这样映射回来时边沿才正好落在原处。

$$
\Omega=\frac2T\tan\frac{\omega}{2};\qquad \Omega_p=\frac2T\tan\frac{\omega_p}{2},\quad \Omega_s=\frac2T\tan\frac{\omega_s}{2}
$$

| 变换 | 频率关系 | 混叠 | 频率刻度 |
| --- | --- | --- | --- |
| 脉冲响应不变 | $\omega=\Omega T$ | 有 | 线性保持 |
| 双线性 | $\Omega=\frac2T\tan\frac{\omega}{2}$ | 无 | 非线性压缩 |

设计五步：预畸变得 $\Omega_p,\Omega_s$ → 求 $N$、$\Omega_c$ → 写 $H_a(s)$ → 代入代换整理成 $H(z)$ → `freqz` 复核。

例：一阶低通 $H_a(s)=\dfrac{\Omega_c}{s+\Omega_c}$ 代入后分子分母同除以 $2+\Omega_cT$，即得标准一阶数字低通；取 $\Omega_c=\frac2T\tan\frac{\omega_c}{2}$ 时数字截止正好是 $\omega_c$。

$$
H(z)=\frac{\Omega_cT(1+z^{-1})}{(2+\Omega_cT)+(\Omega_cT-2)z^{-1}}
$$

### 适用前提

- 双线性对所有类型（低通/高通/带通/带阻）都适用，因为它不依赖带宽限制。
- 预畸变只对"边沿频率"精确，中间频段的映射仍是弯曲的。
- $T$ 只影响频率刻度换算，取 $T=1$ 归一化不影响 $H(z)$ 的形状。

### 常见工程坑点

- 忘了预畸变：通带边沿会明显偏移，指标看着"差一点"却总也调不上。
- 用双线性设计窄带高通/带阻时，靠近 $\pi$ 的边沿被强烈压缩，阶数会突然升高。

## 6. 高通、带通、带阻的设计

低通原型是唯一的"母版"，其他类型靠频率变换得到。变换可以在模拟域做（先变 $H_a(s)$ 再双线性），也可以在数字域做（先得数字低通再做数字频率变换）。

| 路线 | 步骤 | 优点 |
| --- | --- | --- |
| 模拟域变换 | 低通原型 → 模拟高通/带通/带阻 → 双线性 | 公式成熟、工具全 |
| 数字域变换 | 数字低通 → 数字高通/带通/带阻 | 不必重做原型，适合已有低通 |

| 目标 | 代换（$H_{LP}$ 截止归一化为 1） |
| --- | --- |
| 低通（截止 $\Omega_p$） | $s\to s/\Omega_p$ |
| 高通（截止 $\Omega_p$） | $s\to \Omega_p/s$ |
| 带通（$\Omega_{p1},\Omega_{p2}$） | $s\to\dfrac{s^2+\Omega_0^2}{Bs}$，$\Omega_0=\sqrt{\Omega_{p1}\Omega_{p2}}$，$B=\Omega_{p2}-\Omega_{p1}$ |
| 带阻 | $s\to\dfrac{Bs}{s^2+\Omega_0^2}$ |

以数字高通为例六步：写数字指标（注意高通 $\omega_p>\omega_s$）→ 预畸变 → 边沿取倒数换成低通原型指标 → 设计低通原型 → $s\to\Omega_p/s$ 变回高通 → 双线性得 $H(z)$。

高通与带阻**一律用双线性变换**：它们在 $\Omega\to\infty$ 处增益不为零，脉冲响应不变法必然严重混叠。

### 常见工程坑点

- 高通的 $\omega_p$ 与 $\omega_s$ 大小关系与低通相反，照抄低通顺序会把过渡带算成负值。
- 频率变换后代换要作用在整个 $H_a(s)$ 上（含分子），只换分母是最常见的错。

## 7. MATLAB 方法

`*ord` 系列由指标求最小阶数，`butter`/`cheby1`/`ellip` 直接给数字滤波器（内部默认双线性），`bilinear`/`impinvar` 做显式映射，`tf2sos` 转成实现用的二阶节。

| 函数 | 作用 |
| --- | --- |
| `buttord`/`cheb1ord`/`cheb2ord`/`ellipord` | 求最小阶数 $N$ 与截止频率 |
| `butter`/`cheby1`/`cheby2`/`ellip` | 直接设计数字滤波器 |
| `buttap`/`cheb1ap`/`ellipap` | 生成模拟低通原型 |
| `bilinear`／`impinvar` | 双线性／脉冲响应不变映射 |
| `lp2lp`/`lp2hp`/`lp2bp`/`lp2bs` | 模拟频率变换 |
| `freqz`／`tf2sos` | 画频响／转级联二阶节 |

下面这段是巴特沃斯低通的完整流程，并用 `freqz` 复核通带阻带。注意频率参数的单位换算。

```matlab
fs = 10000; fp = 1000; fsb = 2000; ap = 1; as = 40;
wp = 2*pi*fp/fs; ws = 2*pi*fsb/fs;            % 归一化数字频率(rad)
[N, wc] = buttord(wp/pi, ws/pi, ap, as);       % buttord 吃 ω/π
[b, a] = butter(N, wc);                        % 默认双线性变换
[H, w] = freqz(b, a, 1024);
plot(w/pi, 20*log10(abs(H))); grid on;         % 核对 α_p、α_s
sos = tf2sos(b, a);                            % 工程实现用级联型
abs(roots(a)) < 1                              % 稳定性检查
[bz, az] = impinvar(1, [1 1], fs);             % 对照：脉冲响应不变法
```

| 检查项 | 动作 |
| --- | --- |
| 通带/阻带达标 | `freqz` 看 dB 曲线核对 $\alpha_p,\alpha_s$ |
| 稳定性 | `abs(roots(a)) < 1` |
| 阶数是否合理 | 过高会导致数值问题与相位失真，考虑放宽过渡带或换椭圆 |
| 结构 | 高阶用 `tf2sos` 转级联 |
| 有限字长 | 定点前做缩放并检查中间变量范围 |

### 常见工程坑点

- MATLAB 的频率参数默认是"归一化到 Nyquist"（$\omega/\pi$，0–1），不是 rad/s；给 Hz 要除 $f_s/2$，给 rad 要除 $\pi$。
- `butter` 默认已经是双线性，再手动 `bilinear` 一次等于变换两次。
