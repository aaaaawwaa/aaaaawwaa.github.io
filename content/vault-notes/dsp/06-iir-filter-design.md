> [!abstract] 本章在讲什么
> 第 5 章解决了"给定 $H(z)$ 怎么实现"，本章解决"**给定指标，怎么求 $H(z)$**"：
> - **6.1 引言**：IIR 设计的标准流程——数字指标 → 模拟原型 → 模拟滤波器 → 数字映射 → 结构实现。
> - **6.2 IIR 数字滤波器设计的基本概念**：通带/阻带、波纹、衰减这些指标怎么定义？模拟到数字的映射必须满足什么条件？
> - **6.3 模拟滤波器的设计**：巴特沃斯、切比雪夫 I/II、椭圆、贝塞尔；阶数估计与归一化低通原型。
> - **6.4 用脉冲响应不变法设计 IIR 数字低通滤波器**：$h(n)=Th_a(nT)$，$z=e^{sT}$；简单但有**频谱混叠**，只适合低通/带通。
> - **6.5 用双线性变换法设计 IIR 数字低通滤波器**：$s=\frac{2}{T}\frac{1-z^{-1}}{1+z^{-1}}$；无混叠，但有**频率畸变**，需要预畸变。
> - **6.6 数字高通、带通和带阻滤波器的设计**：先做模拟频率变换，再用双线性变换；或直接在数字域做频率变换。
> - **6.7 设计 IIR 数字滤波器的 MATLAB 方法**：`buttord`/`butter`/`bilinear`/`impinvar` 一条龙。
>
> 一句话主线：**IIR 设计 = "借"模拟滤波器的成熟公式，再用一个 $s\to z$ 的映射把模拟 $H_a(s)$ 搬进数字域；脉冲响应不变法保频率刻度但会混叠，双线性变换法不混叠但频率刻度被压弯（需预畸变）。**

> [!note] 记号约定
> - 模拟频率 $\Omega$（rad/s）或 $f$（Hz）；数字频率 $\omega$（rad），$\omega=2\pi f/f_s$
> - 通带边沿 $\Omega_p/\omega_p$；阻带边沿 $\Omega_s/\omega_s$
> - 通带最大衰减 $\alpha_p$（dB）；阻带最小衰减 $\alpha_s$（dB）
> - $\Omega_c$：截止频率（3 dB 点）；$N$：滤波器阶数
> - $H_a(s)$：模拟滤波器；$H(z)$：数字滤波器
> - 双线性变换：$s=\dfrac{2}{T}\dfrac{1-z^{-1}}{1+z^{-1}}$，$T$ 为采样周期（常取 $T=1$ 做归一化）
> - 预畸变：把数字边沿 $\omega$ 先换成模拟边沿 $\Omega=\dfrac{2}{T}\tan\dfrac{\omega}{2}$

# 1. 引言

## 设计流程

IIR 数字滤波器的设计通常走"模拟原型"路线：

```
数字指标（ω_p, ω_s, α_p, α_s）
        │  频率预畸变（双线性变换时）
        ▼
模拟指标（Ω_p, Ω_s, α_p, α_s）
        │  选原型 + 求阶数 N、截止频率 Ω_c
        ▼
模拟滤波器 H_a(s)
        │  s → z 映射（脉冲响应不变 / 双线性）
        ▼
数字滤波器 H(z)
        │  选结构（直接型/级联型/并联型）
        ▼
实现（差分方程 / 信号流图）
```

## 为什么绕道模拟域

| 原因 | 说明 |
| --- | --- |
| 模拟滤波器有闭式公式 | 巴特沃斯、切比雪夫、椭圆都有成熟的 $H_a(s)$ 表达式与阶数估计公式 |
| 设计工具成熟 | MATLAB 的 `buttap`/`cheb1ap`/`ellipap` 直接给原型 |
| 指标直观 | 通带波纹、阻带衰减在模拟域有标准表格 |
| 映射理论完整 | $s\to z$ 的两种经典方法（脉冲响应不变、双线性）都有明确的性质与适用条件 |

# 2. IIR 数字滤波器设计的基本概念

## 幅度指标

一个低通滤波器的典型指标：

| 指标 | 含义 | 典型值 |
| --- | --- | --- |
| 通带截止 $\omega_p$ | 通带边缘，$\lvert H\rvert$ 下降不超过 $\alpha_p$ | 如 $0.2\pi$ |
| 阻带起始 $\omega_s$ | 阻带边缘，$\lvert H\rvert$ 不超过 $\alpha_s$ | 如 $0.3\pi$ |
| 通带波纹 $\alpha_p$ | 通带内最大衰减（dB） | 1 dB / 3 dB |
| 阻带衰减 $\alpha_s$ | 阻带最小衰减（dB） | 40 dB / 60 dB |
| 过渡带 | $\omega_s-\omega_p$ | 越窄，阶数越高 |

> [!info] Def 1 数字滤波器设计指标
> **数字滤波器设计指标**通常用幅频特性给出：通带边沿 $\omega_p$、阻带边沿 $\omega_s$、通带最大衰减 $\alpha_p$、阻带最小衰减 $\alpha_s$。设计的目标是找一个因果稳定的 $H(z)$，使其幅频特性满足这些不等式。

用 dB 表示：

$$\alpha_p=-20\log_{10}\left|H(e^{j\omega_p})\right|,\qquad \alpha_s=-20\log_{10}\left|H(e^{j\omega_s})\right|$$

## 映射必须满足的条件

从模拟 $H_a(s)$ 到数字 $H(z)$，映射 $s\to z$ 必须满足：

1. **虚轴 → 单位圆**：$s=j\Omega$ 映射到 $z=e^{j\omega}$，频率轴对频率轴
2. **左半平面 → 单位圆内**：稳定的模拟滤波器映射后仍稳定
3. **因果性保持**：$H_a(s)$ 因果 ⇒ $H(z)$ 因果
4. **频率响应形状尽量保持**：通带/阻带的相对关系不变

两条经典映射：

| 方法 | 映射 | 频率关系 | 混叠 |
| --- | --- | --- | --- |
| 脉冲响应不变法 | $z=e^{sT}$ | $\omega=\Omega T$（线性） | **有** |
| 双线性变换法 | $s=\frac{2}{T}\frac{1-z^{-1}}{1+z^{-1}}$ | $\Omega=\frac{2}{T}\tan\frac{\omega}{2}$（非线性） | **无** |

# 3. 模拟滤波器的设计

## 巴特沃斯滤波器

> [!info] Def 2 巴特沃斯滤波器
> **巴特沃斯滤波器**（Butterworth filter）的幅平方特性为
> $$\left|H_a(j\Omega)\right|^2=\frac{1}{1+\left(\dfrac{\Omega}{\Omega_c}\right)^{2N}}$$
> 它在 $\Omega=0$ 处**最平坦**（前 $2N-1$ 阶导数为零），在 $\Omega=\Omega_c$ 处衰减 3 dB，故 $\Omega_c$ 也称 **3 dB 截止频率**。

- 通带无波纹、阻带单调下降

$$N\ge\frac{\log_{10}\left[\dfrac{10^{\alpha_s/10}-1}{10^{\alpha_p/10}-1}\right]}{2\log_{10}\left(\dfrac{\Omega_s}{\Omega_p}\right)}$$

取满足条件的最小整数。

## 切比雪夫滤波器

> [!info] Def 3 切比雪夫滤波器
> **切比雪夫 I 型滤波器**（Chebyshev type I filter）的幅平方特性为
> $$\left|H_a(j\Omega)\right|^2=\frac{1}{1+\varepsilon^2T_N^2\left(\dfrac{\Omega}{\Omega_p}\right)}$$
> 其中 $T_N(x)$ 为 $N$ 阶切比雪夫多项式，$\varepsilon$ 由通带波纹决定。它在通带内**等波纹**、阻带单调下降。

- 通带波纹 $\alpha_p$ 与 $\varepsilon$ 的关系：$\varepsilon=\sqrt{10^{\alpha_p/10}-1}$
- 相同阶数下，切比雪夫的过渡带比巴特沃斯更陡
- **切比雪夫 II 型**（ inverse Chebyshev）则是**阻带等波纹**、通带单调

## 椭圆滤波器

> [!info] Def 4 椭圆滤波器
> **椭圆滤波器**（elliptic filter，也称 Cauer filter）在通带和阻带都呈**等波纹**，相同阶数下过渡带最陡；代价是相位非线性最严重，且阻带衰减的极点分布更复杂。

| 类型 | 通带 | 阻带 | 过渡带陡度 | 相位线性 |
| --- | --- | --- | --- | --- |
| 巴特沃斯 | 平坦 | 单调 | 最缓 | 最好 |
| 切比雪夫 I | 等波纹 | 单调 | 较陡 | 较差 |
| 切比雪夫 II | 单调 | 等波纹 | 较陡 | 较差 |
| 椭圆 | 等波纹 | 等波纹 | **最陡** | 最差 |
| 贝塞尔 | 平坦 | 单调 | 最缓 | **最好**（近似线性相位） |

> [!tip] 选型口诀
> **要平坦选巴特沃斯，要陡选椭圆，要相位选贝塞尔，折中选切比雪夫。**

# 4. 用脉冲响应不变法设计 IIR 数字低通滤波器

## 基本思想

> [!info] Def 5 脉冲响应不变法
> **脉冲响应不变法**（impulse invariance method）令数字滤波器的单位冲激响应等于模拟滤波器冲激响应的等间隔采样：
> $$h(n)=T\,h_a(nT)$$
> 其中 $T$ 为采样周期。对应的映射为
> $$z=e^{sT}$$

## 映射关系

若 $H_a(s)$ 有极点 $s_k$，则 $H(z)$ 的极点为

$$z_k=e^{s_kT}$$

- $s$ 左半平面 → $z$ 单位圆内（稳定）
- $s$ 虚轴 → $z$ 单位圆（频率轴）
- 频率关系：$\omega=\Omega T$（**线性**，频率刻度保持）

## 混叠问题

由采样定理，$H(z)$ 的频响是 $H_a(j\Omega)$ 的周期延拓：

$$H(e^{j\omega})=\frac{1}{T}\sum_{k=-\infty}^{\infty}H_a\left(j\frac{\omega-2\pi k}{T}\right)$$

因此若 $H_a(j\Omega)$ 在 $\Omega>\pi/T$ 处不为零，就会发生**频谱混叠**：

| 滤波器类型 | 混叠影响 | 是否适用 |
| --- | --- | --- |
| 低通 | 高频衰减大，混叠小 | ✅ 适用 |
| 带通 | 若高频衰减足够，混叠小 | ✅ 可用 |
| 高通 | 高频增益大，严重混叠 | ❌ 不适用 |
| 带阻 | 高频/低频都可能混叠 | ⚠️ 慎用 |

> [!example] 一阶低通的脉冲响应不变法
> 模拟滤波器 $H_a(s)=\dfrac{a}{s+a}$，冲激响应 $h_a(t)=ae^{-at}u(t)$。
> 采样：$h(n)=T a e^{-anT}u(n)$，取 $z$ 变换：
> $$H(z)=\frac{Ta}{1-e^{-aT}z^{-1}}$$
> 极点 $s=-a$ → $z=e^{-aT}$，确实落在单位圆内。
> 若 $aT\ll1$，$H(z)\approx\dfrac{aT}{1-(1-aT)z^{-1}}$，与模拟滤波器在低频段一致。

> [!warning] 脉冲响应不变法的两个坑
> 1. **混叠不可避免**：即使低通，若阻带衰减不够，高频仍会折回通带。设计时要保证 $\alpha_s$ 足够大，或提高采样率。
> 2. **$T$ 的选择**：$h(n)=Th_a(nT)$ 中的 $T$ 不能省，否则直流增益会差 $1/T$。MATLAB 的 `impinvar` 默认取 $T=1$，需要自己核对增益。

# 5. 用双线性变换法设计 IIR 数字低通滤波器

## 基本思想

> [!info] Def 6 双线性变换法
> **双线性变换法**（bilinear transform）用代换
> $$s=\frac{2}{T}\frac{1-z^{-1}}{1+z^{-1}}\qquad\Longleftrightarrow\qquad z=\frac{1+(T/2)s}{1-(T/2)s}$$
> 把模拟 $H_a(s)$ 映射为数字 $H(z)$。

- 这是一个**双线性分式变换**：$s$ 平面 → $z$ 平面的一一映射
- $s$ 左半平面 → $z$ 单位圆内（稳定）
- $s$ 虚轴 → $z$ 单位圆（频率轴）
- **没有混叠**：整个 $j\Omega$ 轴被压缩到单位圆上，不会周期重复

## 频率畸变

> [!info] Def 7 频率畸变与预畸变
> 双线性变换的频率关系为
> $$\Omega=\frac{2}{T}\tan\frac{\omega}{2}$$
> 这是**非线性**的：$\omega$ 从 $0$ 到 $\pi$ 时，$\Omega$ 从 $0$ 到 $\infty$。为了让数字边沿 $\omega_p,\omega_s$ 映射到正确的模拟边沿，需要先做**预畸变**（prewarping）：
> $$\Omega_p=\frac{2}{T}\tan\frac{\omega_p}{2},\qquad \Omega_s=\frac{2}{T}\tan\frac{\omega_s}{2}$$

> [!important] 双线性变换的设计步骤
> 1. 由数字指标 $\omega_p,\omega_s$ 做**预畸变**，得到模拟指标 $\Omega_p,\Omega_s$
> 2. 用模拟原型（巴特沃斯/切比雪夫/椭圆）求阶数 $N$ 与截止频率 $\Omega_c$
> 3. 写出模拟 $H_a(s)$
> 4. 代入 $s=\frac{2}{T}\frac{1-z^{-1}}{1+z^{-1}}$，整理成 $H(z)$
> 5. 检查数字频响（`freqz`），必要时调整阶数或指标

> [!example] 双线性变换的一阶低通
> $H_a(s)=\dfrac{\Omega_c}{s+\Omega_c}$，代入 $s=\frac{2}{T}\frac{1-z^{-1}}{1+z^{-1}}$：
> $$H(z)=\frac{\Omega_c(1+z^{-1})}{\frac{2}{T}(1-z^{-1})+\Omega_c(1+z^{-1})}
> =\frac{\Omega_c T(1+z^{-1})}{(2+\Omega_cT)+( \Omega_cT-2)z^{-1}}$$
> 分子分母同除 $(2+\Omega_cT)$，得到标准一阶数字低通形式。
> 预畸变：$\Omega_c=\frac{2}{T}\tan\frac{\omega_c}{2}$，这样数字截止频率正好是 $\omega_c$。

# 6. 数字高通、带通和带阻滤波器的设计

## 两条路线

> [!info] Def 8 频率变换
> **频率变换**（frequency transformation）是把低通原型的频率轴映射到高通/带通/带阻频率轴的过程。可以在**模拟域**做（先变换 $H_a(s)$，再双线性），也可以在**数字域**做（先得到数字低通，再用数字频率变换）。

| 路线 | 步骤 | 优点 |
| --- | --- | --- |
| 模拟域变换 | 低通原型 → 模拟高通/带通/带阻 → 双线性 | 公式成熟，MATLAB 工具全 |
| 数字域变换 | 数字低通 → 数字高通/带通/带阻 | 不需要重新设计模拟原型，适合已有低通 |

## 模拟频率变换公式

以低通原型 $H_{LP}(s)$（截止 $\Omega_c=1$）为基准：

| 目标 | 代换 |
| --- | --- |
| 低通（截止 $\Omega_p$） | $s\to\dfrac{s}{\Omega_p}$ |
| 高通（截止 $\Omega_p$） | $s\to\dfrac{\Omega_p}{s}$ |
| 带通（$\Omega_{p1},\Omega_{p2}$） | $s\to\dfrac{s^2+\Omega_0^2}{Bs}$，$\Omega_0=\sqrt{\Omega_{p1}\Omega_{p2}}$，$B=\Omega_{p2}-\Omega_{p1}$ |
| 带阻 | $s\to\dfrac{Bs}{s^2+\Omega_0^2}$ |

> [!warning] 高通不能用脉冲响应不变法
> 高通滤波器在 $\Omega\to\infty$ 处增益不为零，脉冲响应不变法会产生严重混叠；**高通/带阻一律用双线性变换法**。

## 设计步骤（以数字高通为例）

1. 数字指标 $\omega_p,\omega_s$（注意高通是 $\omega_p>\omega_s$）
2. 预畸变：$\Omega_p=\frac{2}{T}\tan\frac{\omega_p}{2}$，$\Omega_s=\frac{2}{T}\tan\frac{\omega_s}{2}$
3. 模拟高通指标 → 低通原型指标（频率倒数变换）
4. 设计低通原型（巴特沃斯/切比雪夫/椭圆）
5. 模拟低通 → 模拟高通（$s\to\Omega_p/s$）
6. 双线性变换 → 数字高通 $H(z)$

> [!example] 数字高通的设计思路
> 要求：$f_s=10$ kHz，通带 $f_p=2$ kHz，阻带 $f_s=1$ kHz，$\alpha_p=1$ dB，$\alpha_s=40$ dB。
> 预畸变后得到模拟高通指标；把高通边沿取倒数，转成低通原型指标；设计低通原型后再做 $s\to\Omega_p/s$，最后双线性。MATLAB 里直接用 `buttord` + `butter(...,'high')` 即可，内部做的就是这件事。

# 7. 设计 IIR 数字滤波器的 MATLAB 方法

## 常用函数

| 函数 | 作用 |
| --- | --- |
| `buttord` / `cheb1ord` / `cheb2ord` / `ellipord` | 由指标求最小阶数 $N$ 与截止频率 |
| `butter` / `cheby1` / `cheby2` / `ellip` | 直接设计数字滤波器（默认双线性） |
| `buttap` / `cheb1ap` / `cheb2ap` / `ellipap` | 生成模拟低通原型（零极点增益） |
| `bilinear` | 双线性变换（模拟 → 数字） |
| `impinvar` | 脉冲响应不变法（模拟 → 数字） |
| `lp2lp` / `lp2hp` / `lp2bp` / `lp2bs` | 模拟频率变换 |
| `freqz` | 画数字频响 |
| `tf2sos` | 转成级联二阶节（实现用） |

## 完整示例：巴特沃斯低通

```matlab
fs = 10000;                       % 采样率
fp = 1000; fsb = 2000;            % 通带/阻带边沿（Hz）
ap = 1; as = 40;                  % 通带波纹/阻带衰减（dB）
wp = 2*pi*fp/fs; ws = 2*pi*fsb/fs;% 归一化数字频率（rad）

[N, wc] = buttord(wp/pi, ws/pi, ap, as);   % 注意 buttord 用归一化到 π 的频率
[b, a] = butter(N, wc);                     % 默认双线性变换
[H, w] = freqz(b, a, 1024);
plot(w/pi, 20*log10(abs(H))); grid on;
xlabel('\omega/\pi'); ylabel('dB');

% 转成级联型（工程实现用）
[sos, g] = tf2sos(b, a);

% 若要用脉冲响应不变法（只适合低通/带通）
[bz, az] = impinvar(1, [1 1], fs);          % 例：H_a(s)=1/(s+1)
```

> [!warning] MATLAB 频率单位
> `buttord`/`butter` 的频率参数默认是**归一化到 Nyquist 频率**（即 $\omega/\pi$，范围 0–1），不是 rad/s。若给的是 Hz，要先除以 $f_s/2$；若给的是 rad，要先除以 $\pi$。这是最常见的错误来源。

## 设计检查清单

1. **通带/阻带是否满足**：`freqz` 看 dB 曲线，核对 $\alpha_p,\alpha_s$
2. **稳定性**：`abs(roots(a)) < 1`
3. **阶数是否合理**：阶数过高会导致数值问题和相位失真，考虑放宽过渡带或换椭圆
4. **结构**：高阶用 `tf2sos` 转级联型
5. **有限字长**：定点实现前做缩放，检查中间变量范围

> [!tip] 本章收官
> 本章的主线是"**借模拟之壳，生数字之蛋**"：
> 1. **指标**（6.2）：通带/阻带/波纹/衰减，映射要保稳定、保频率轴；
> 2. **原型**（6.3）：巴特沃斯最平坦、切比雪夫最常用、椭圆最陡、贝塞尔相位最好；
> 3. **脉冲响应不变法**（6.4）：$z=e^{sT}$，频率线性但会混叠，只适合低通/带通；
> 4. **双线性变换**（6.5）：$s=\frac{2}{T}\frac{1-z^{-1}}{1+z^{-1}}$，无混叠但频率非线性，需预畸变，适合所有类型；
> 5. **频率变换**（6.6）：低通原型 → 高通/带通/带阻；
> 6. **MATLAB**（6.7）：`*ord` + `*` + `tf2sos` 一条龙。
>
> 一句话：**IIR 设计的关键不是公式，而是选对映射：要频率刻度准、能接受混叠 → 脉冲响应不变；要无混叠、能接受预畸变 → 双线性。** 下一章转向 FIR——它没有反馈，可以做到严格线性相位，但需要更高的阶数。

```
  │     ├─ h(n)=T h_a(nT)，z=e^{sT}
  │     ├─ 频率线性：ω=ΩT
  │     ├─ 有混叠：H(e^{jω})=1/T ΣH_a(j(ω−2πk)/T)
  │     └─ 适用：低通/带通；不适用：高通/带阻
  │
  ├─ 5. 双线性变换法
  │     ├─ s=2/T·(1−z⁻¹)/(1+z⁻¹)
  │     ├─ 无混叠，左半平面→单位圆内
  │     ├─ 频率畸变：Ω=2/T·tan(ω/2)
  │     └─ 预畸变：Ω=2/T·tan(ω/2)
  │
  ├─ 6. 频率变换
  │     ├─ 低通→高通：s→Ω_p/s
  │     ├─ 低通→带通：s→(s²+Ω₀²)/(Bs)
  │     ├─ 低通→带阻：s→Bs/(s²+Ω₀²)
  │     └─ 高通/带阻必须用双线性
  │
  └─ 7. MATLAB
        ├─ buttord/cheb1ord/ellipord
        ├─ butter/cheby1/ellip
        ├─ bilinear/impinvar
        ├─ lp2lp/lp2hp/lp2bp/lp2bs
        └─ freqz/tf2sos
```
