# 附录. 随机变量函数与随机数生成

> [!abstract] 📌 核心导读
> 本篇补上 [[vault-notes/math/probability/03-random-variables-distributions]] 留下的两块空白，并按**两条互逆的主线**组织：
>
> - **正向（求分布）**：已知 $X$（或 $(X,Y)$）的分布，求 $Y=g(X)$ 的分布 —— §2
> - **反向（造样本）**：已知目标分布，用均匀随机数把它"造"出来 —— §3
>
> 两条线在**通信仿真**处汇合（§4）：要仿真高斯白噪声、瑞利衰落、误码率，就必须会**生成**这些分布；而验证仿真对不对，又要会**求**生成结果的分布。
>
> 本篇所有 Matlab 代码与结论均已在本机实机跑通（N 达 3×10⁵～2×10⁶），图中数据是真实的仿真输出。


> [!note] 记号约定
> - $f_X,f_Y$：一维密度；$f_{XY}$：联合密度；$F$：分布函数
> - $U\sim U(0,1)$：均匀随机数（所有生成算法的源头）
> - 逆变换：$X=F^{-1}(U)$；舍选法：包络 $Mg(x)\ge f(x)$
> - 雅可比：$J=\partial(x,y)/\partial(z,w)$
> - 相关高斯：$\boldsymbol{\Sigma}=LL^T$（Cholesky 分解）
> - 蒙特卡洛：样本量 $N$，估计误差 $\propto1/\sqrt N$
> - 本篇代码为 MATLAB；`rand`/`randn` 分别生成均匀/标准正态

# 1. 二维随机变量速览

[[vault-notes/math/probability/03-random-variables-distributions]] 只讲了一维，但**随机变量函数**的绝大部分内容（卷积公式、雅可比变换）都建立在二维之上。这里先补最小必要的脚手架。

## 1.1 联合分布与联合密度

> [!info] Def 1 联合分布函数
> **联合分布函数**（joint CDF）：

$$
F_{XY}(x,y) = P(X \le x,\ Y \le y)
$$

**联合概率密度**（连续型，$F$ 二阶可导时）：

$$
f_{XY}(x,y) = \frac{\partial^2 F_{XY}(x,y)}{\partial x\,\partial y}, \qquad F_{XY}(x,y) = \int_{-\infty}^{x}\int_{-\infty}^{y} f_{XY}(u,v)\,\mathrm{d}v\,\mathrm{d}u
$$

两条基本性质：$f_{XY}(x,y)\ge 0$，且 $\displaystyle\iint_{\mathbb{R}^2} f_{XY}(x,y)\,\mathrm{d}x\,\mathrm{d}y = 1$。

## 1.2 边缘分布：把另一个变量"积掉"

$$
f_X(x) = \int_{-\infty}^{\infty} f_{XY}(x,y)\,\mathrm{d}y, \qquad f_Y(y) = \int_{-\infty}^{\infty} f_{XY}(x,y)\,\mathrm{d}x
$$

> [!tip] 一句话记忆
> **联合 → 边缘靠积分，边缘 → 联合需要独立性假设**（一般不能反推）。

## 1.3 独立性判据

$X$ 与 $Y$ **独立** ⟺ 对一切 $x,y$ 有

$$
f_{XY}(x,y) = f_X(x)\,f_Y(y) \qquad (\text{或 } F_{XY}=F_X F_Y)
$$

> [!warning] 常见误区
> **不相关 ≠ 独立**（一般情形）。但对**二维高斯**，不相关 $\Leftrightarrow$ 独立 —— 这条性质在 §3.5 生成相关高斯时会用到。

## 1.4 条件分布

$$
f_{Y|X}(y|x) = \frac{f_{XY}(x,y)}{f_X(x)} \quad (f_X(x) > 0)
$$

这是 [[vault-notes/math/probability/02-conditional-probability-independence|条件概率]] 在连续情形下的对应物（$\frac{\text{联合}}{\text{边缘}}$ 正是 $P(AB)/P(A)$ 的密度版本）。


# 2. 随机变量函数：从一维到多维

## 2.1 一维回顾与补强

[[vault-notes/math/probability/03-random-variables-distributions]] §六 给出了三步**分布函数法**（万用）与**单调函数公式**。这里补上介于两者之间的常见情形。

> [!important] 一维求分布的三条路（按优先级选用）
>
> **① 分布函数法**（永远可用）
> $$
> F_Y(y) = P(g(X)\le y) \;\Longrightarrow\; \text{解不等式得 } x \text{ 的范围} \;\Longrightarrow\; \text{用 } F_X \text{ 表示} \;\Longrightarrow\; f_Y = F_Y'
> $$
>
> **② 单调可导公式**（$g$ 严格单调时最快）
> $$
> f_Y(y) = f_X\big(h(y)\big)\,\big|h'(y)\big|, \qquad h = g^{-1}
> $$
>
> **③ 非单调：分段求和**（如 $Y=X^2$）
> $$
> f_Y(y) = \sum_{i} \frac{f_X(x_i)}{\big|g'(x_i)\big|}, \qquad x_i \text{ 为 } g(x)=y \text{ 的全部实根}
> $$

> [!example] 非单调典型：$Y = X^2$（$X\sim N(0,1)$）
> 对 $y>0$，方程 $x^2=y$ 有两根 $x_{1,2}=\pm\sqrt y$，且 $|g'|=2\sqrt y$：
> $$
> f_Y(y) = \frac{f_X(\sqrt y) + f_X(-\sqrt y)}{2\sqrt y} = \frac{1}{\sqrt{2\pi y}}\,e^{-y/2}, \qquad y>0
> $$
> 即**自由度为 1 的卡方分布** $\chi^2(1)$ —— 这正是通信中"能量检测"统计量（见 [[vault-notes/math/probability/03-random-variables-distributions]] 例 11）的理论基础。

## 2.2 二维函数：$Z=g(X,Y)$ 的分布

**分布函数法（通用）**：先算

$$
F_Z(z) = \iint_{g(x,y)\le z} f_{XY}(x,y)\,\mathrm{d}x\,\mathrm{d}y
$$

再对 $z$ 求导。难点在于**把区域 $g(x,y)\le z$ 画对**。

### (1) 和的分布：卷积公式 ⭐⭐⭐

对 $Z = X+Y$（$X,Y$ 独立）：

$$
\boxed{\;f_Z(z) = \int_{-\infty}^{\infty} f_X(x)\,f_Y(z-x)\,\mathrm{d}x = f_X * f_Y\;}
$$

> [!important] 几何理解（记这一句就够）
> 卷积三动作：**把 $f_Y$ 翻转（$z-x$）、平移 $z$、与 $f_X$ 相乘积分**。

### (2) 其他四则运算的公式（$X,Y$ 独立）

| 运算 | 密度公式 | 备注 |
| --- | --- | --- |
| $Z=X+Y$ | $f_Z(z)=\displaystyle\int f_X(x)f_Y(z-x)\mathrm{d}x$ | 卷积 |
| $Z=X-Y$ | $f_Z(z)=\displaystyle\int f_X(x)f_Y(x-z)\mathrm{d}x$ | 即 $X+(-Y)$，翻转一支即可 |
| $Z=XY$ | $f_Z(z)=\displaystyle\int \frac{1}{\vert x\vert }f_X(x)f_Y\!\left(\frac{z}{x}\right)\mathrm{d}x$ | 对 $x$ 换元 |
| $Z=X/Y$ | $f_Z(z)=\displaystyle\int \vert x\vert f_X(x)f_Y(zx)\,\mathrm{d}x$ | 商的分布，注意 $\vert x\vert $ 因子 |

> [!tip] 记忆窍门
> 四条公式统一来自同一个换元框架：**先把 $Z=g(X,Y)$ 与一个辅助变量配成一对一变换，再用下节的雅可比法**。不必死记，会推即可。

## 2.3 多维变换：雅可比行列式法 ⭐⭐⭐

设 $(U,V) = (g_1(X,Y),\ g_2(X,Y))$ 是**一对一**变换，反解出

$$
x = x(u,v), \qquad y = y(u,v)
$$

则联合密度：

$$
\boxed{\;f_{UV}(u,v) = f_{XY}\big(x(u,v),\ y(u,v)\big)\cdot |J|\;}, \qquad J = \det\begin{bmatrix} \dfrac{\partial x}{\partial u} & \dfrac{\partial x}{\partial v}\\[2mm] \dfrac{\partial y}{\partial u} & \dfrac{\partial y}{\partial v}\end{bmatrix}
$$

> [!warning] 三个易错点
> 1. **$|J|$ 要用绝对值**；$J$ 是**反函数**（$x,y$ 对 $u,v$）的雅可比，别写反方向。
> 2. 变换后**必须写清新的定义域**（$u,v$ 的取值范围）——这是最容易漏分的地方。
> 3. 求单个 $g(X,Y)$ 的分布时，可**人为添一个辅助变量**（如 $V=X$）凑成一对一，最后把 $v$ 积掉。

> [!example] 用雅可比法推出瑞利分布（几何来源）⭐
> 设 $X,Y$ 独立同分布 $N(0,\sigma^2)$（接收信号的同相/正交分量）。作**极坐标变换**：
> $$
> x = r\cos\theta, \qquad y = r\sin\theta \quad (r\ge 0,\ 0\le\theta<2\pi)
> $$
> 雅可比：
> $$
> J = \det\begin{bmatrix} \cos\theta & -r\sin\theta \\ \sin\theta & r\cos\theta\end{bmatrix} = r\cos^2\theta + r\sin^2\theta = r
> $$
> 故
> $$
> f_{R\Theta}(r,\theta) = f_X(r\cos\theta)\,f_Y(r\sin\theta)\cdot r = \frac{r}{2\pi\sigma^2}\exp\!\left(-\frac{r^2}{2\sigma^2}\right)
> $$
> 对 $\theta$ 积分掉（被积函数与 $\theta$ 无关，乘 $2\pi$）：
> $$
> \boxed{\;f_R(r) = \frac{r}{\sigma^2}\exp\!\left(-\frac{r^2}{2\sigma^2}\right),\qquad r\ge 0\;}
> $$
> **这就是瑞利分布**——[[vault-notes/math/probability/03-random-variables-distributions]] 里那句"瑞利 = 两个独立同方差高斯变量的模"的完整推导。同时可见 $\theta$ 服从**均匀分布**且与 $R$ **独立**，这正是 [[vault-notes/communication/03-random-processes]] 中窄带噪声"包络瑞利、相位均匀、二者独立"的由来。

## 2.4 顺序统计量与极值 ⭐⭐

> [!info] Def 2 顺序统计量
> 将样本 $X_1,\dots,X_n$ 从小到大排列为 $X_{(1)}\le\cdots\le X_{(n)}$，称 $X_{(k)}$ 为**第 $k$ 个顺序统计量**（order statistic）。$X_{(1)}$ 与 $X_{(n)}$ 分别为最小值与最大值。

设 $X_1,\dots,X_n$ **独立同分布**，分布函数 $F(x)$、密度 $f(x)$。

**最大值 $Z=\max(X_1,\dots,X_n)$**：

$$
F_{max}(z) = P(\text{全部} \le z) = \big[F(z)\big]^n \qquad\Longrightarrow\qquad f_{max}(z) = n\big[F(z)\big]^{n-1}f(z)
$$

**最小值 $Z=\min(X_1,\dots,X_n)$**：

$$
F_{min}(z) = 1 - \big[1-F(z)\big]^n \qquad\Longrightarrow\qquad f_{min}(z) = n\big[1-F(z)\big]^{n-1}f(z)
$$

**第 $k$ 个次序统计量 $X_{(k)}$**：

$$
f_{X_{(k)}}(z) = \frac{n!}{(k-1)!\,(n-k)!}\,\big[F(z)\big]^{k-1}\big[1-F(z)\big]^{n-k}f(z)
$$

> [!tip] 工程解释（可靠性/分集）
> - **串联系统**（全部元件都得工作）寿命 = $\min$ → 系统比最弱的元件还短命
> - **并联系统**（有一个工作就行）寿命 = $\max$ → 冗余带来增益
> - 通信中的**选择式分集**：$n$ 条支路取信噪比最大者 → 正是 $\max$ 的分布；支路数 $n$ 增大，$F_{max}$ 迅速右移（分集增益的来源）
>
> $\max$ 的推导只需一句"最大值不超过 $z$ ⟺ 每一个都不超过 $z$"，这是**独立性**给出的最大便利。


# 3. 随机变量生成：从均匀数到任意分布

> [!abstract] 本节要解决的问题
> 计算机只能给你**均匀分布**和（由它派生的）正态分布随机数。要仿真任意分布（指数、瑞利、莱斯、对数正态……），必须掌握**变换与抽样算法**。

## 3.1 源头：均匀随机数

### (1) 线性同余发生器 LCG

$$
x_{n+1} = (a\,x_n + c) \bmod m, \qquad u_n = x_n/m
$$

参数选择决定周期。**Park–Miller 最小标准**取 $a=16807$、$m=2^{31}-1$、$c=0$。

**满周期条件（Hull–Dobell 定理）**：$c$ 与 $m$ 互素；$a-1$ 被 $m$ 的所有素因子整除；若 $m$ 是 4 的倍数则 $a-1$ 也被 4 整除。

> [!note] 实机验证结论（本篇代码输出）
> - Park–Miller（$m=2^{31}-1,\ a=16807$，N=2×10⁵）：均值 **0.50015**（理论 0.5）、方差 **0.08339**（理论 1/12≈0.08333）
> - 卡方均匀性检验：$\chi^2 = 2.62$，远小于自由度 9 的 5% 临界值 16.92 → **接受均匀假设**
> - 小模数演示 $m=17,a=3$：序列 1,3,9,10,13,5,15,11,16,14,8,7,… **周期恰为 16**（满周期）
> - $m=16,a=5,c=3$：周期 **16**（满周期，验证 Hull–Dobell 条件）

### (2) Matlab 用法与陷阱

```matlab
rng(42);              % 固定种子，保证结果可复现（写论文/交作业必加）
u  = rand(1,N);       % U(0,1) 均匀
z  = randn(1,N);      % N(0,1) 标准正态

```

> [!warning] 三个坑
> 1. **不设 `rng`**：每次结果不同，无法复现，调试时最浪费时间。
> 2. **`rand` 与 `randn` 混用**：二者共享随机流，顺序变了结果就变。
> 3. **`randi` 是离散均匀**，不要拿它当连续均匀用。

## 3.2 逆变换法 ⭐⭐⭐（最重要）

> [!info] Def 3 逆变换法（基本定理）
> 设 $F(x)$ 是任意（连续且严格单调的）分布函数，$U\sim U(0,1)$，则
> $$
> X = F^{-1}(U)
> $$
> 服从分布 $F$。

**证明（三行）**：

$$
P(X \le x) = P\big(F^{-1}(U)\le x\big) = P\big(U \le F(x)\big) = F(x)
$$

最后一步用了 $U$ 在 $(0,1)$ 上均匀分布、$F(x)\in[0,1]$ 的性质。∎

**常用分布的逆变换公式**：

| 目标分布 | 生成公式 | 说明 |
| --- | --- | --- |
| 均匀 $U(a,b)$ | $a+(b-a)U$ | 线性缩放 |
| 指数 $E(\lambda)$ | $-\dfrac{1}{\lambda}\ln(1-U)$ 或 $-\dfrac{1}{\lambda}\ln U$ | $1-U$ 与 $U$ 同分布，可为省一次减法直接用 $U$ |
| **瑞利** $R(\sigma)$ | $\sigma\sqrt{-2\ln U}$ | $F(x)=1-e^{-x^2/2\sigma^2}$ 的反函数 |
| 威布尔 $W(k,\lambda)$ | $\lambda(-\ln U)^{1/k}$ | 瑞利是 $k=2$ 的特例 |
| 逻辑分布 | $\ln\dfrac{U}{1-U}$ | — |
| 离散分布 $P(X=x_k)=p_k$ | 逐个累加，取 $U$ 落入的区间 | 见表下方说明 |

**离散型做法**：算出累积概率 $F_k=\sum_{i\le k}p_i$，取 $k$ 使 $U\in(F_{k-1},F_k]$。注意 $F$ 是**阶梯函数**，此时 $F^{-1}$ 取左端点（约定 $U\in(F_{k-1},F_k]$ 对应 $x_k$，恰好是右连续的那个）。

**局限**：只适用于**能写出 $F^{-1}$ 解析式**的分布。正态、莱斯、Gamma 等没有初等反函数 —— 所以需要下面两节。

> [!note] 实机验证结论
> - 指数（$\lambda=2$，N=3×10⁵）：均值 **0.5006**（理论 0.5）、方差 **0.2500**（理论 0.25）
> - 瑞利（$\sigma=1.5$，N=3×10⁵）：均值 **1.8801**（理论 1.8800）、$E[X^2]=$ **4.4979**（理论 4.5）
> - **KS 统计量 0.00122** < 5% 临界值 0.00248 → 接受瑞利分布假设
> - 用 $U$ 与用 $1-U$ 生成的中位数分别为 1.7667 / 1.7655（理论 1.7661），确证二者同分布

## 3.3 舍选法（拒绝法）⭐⭐

**适用**：目标密度 $f(x)$ 形式复杂、但**能找到一个容易抽样的包络** $M\,g(x)\ge f(x)$ 时。

> [!info] Def 4 舍选法（拒绝法）
> 1. 从**建议分布** $g(x)$ 抽一个样本 $Y$
> 2. 从 $U(0,1)$ 抽一个数 $U$

## 3.4 Box–Muller 与 Marsaglia 极坐标法 ⭐⭐⭐

### (1) Box–Muller 变换

设 $U_1, U_2$ **独立**同服从 $U(0,1)$，令

$$
R = \sqrt{-2\ln U_1}, \qquad \Theta = 2\pi U_2
$$

$$
Z_1 = R\cos\Theta = \sqrt{-2\ln U_1}\,\cos(2\pi U_2), \qquad Z_2 = \sqrt{-2\ln U_1}\,\sin(2\pi U_2)
$$

> [!info] Def 5 Box–Muller 变换
> **$Z_1$ 与 $Z_2$ 是相互独立的标准正态随机变量**，即 $Z_1,Z_2 \overset{iid}{\sim} N(0,1)$。
> **两个均匀数 → 两个独立正态数**，一次变换产出两个，效率很高。

**推导思路**：这就是 §2.3 的反向操作。那里用雅可比从 $(X,Y)$ 推出 $(R,\Theta)$ 的联合密度 $\frac{r}{2\pi\sigma^2}e^{-r^2/2\sigma^2}$；这里反过来，**先独立地产生 $R$ 与 $\Theta$**（$R$ 用逆变换法：$R=\sigma\sqrt{-2\ln U_1}$；$\Theta$ 均匀），再变换回直角坐标即可得到独立的正态分量。

**为什么必须用变换法**：正态分布函数 $\Phi(x)$ 无初等反函数，逆变换法失效；而 Box–Muller 把"求 $\Phi^{-1}$"绕开了。

### (2) Marsaglia 极坐标法（免三角函数，工程常用）

1. 重复抽 $V_1,V_2 \sim U(-1,1)$，直到 $S=V_1^2+V_2^2 < 1$（落在单位圆内）
2. 计算 $f = \sqrt{\dfrac{-2\ln S}{S}}$
3. 输出 $Z_1 = V_1 f$、$Z_2 = V_2 f$（两个独立标准正态）

平均每 4 次尝试接受 $\pi$ 次（概率 $\pi/4\approx0.785$），且省掉了 sin/cos 调用 —— **Matlab 的 `randn` 内部就是这类算法**。

> [!note] 实机验证结论（N=4×10⁵）
> - Box–Muller：均值 **0.0024 / 0.0030**（理论 0）、标准差 **1.0016 / 1.0010**（理论 1）、峰度 **3.0112**（理论 3）
> - **两分量相关系数 0.00104**（理论 0）→ 验证了"$Z_1,Z_2$ 独立"
> - KS 统计量 **0.00175** < 临界 0.00215 ✓；Marsaglia 法同样通过
> - 与内置 `randn` 的 5%/25%/50%/75%/95% 分位数逐点吻合

## 3.5 相关随机变量与 Cholesky 分解 ⭐⭐

前述方法产出的分量都是**相互独立**的。通信中的多天线、多径、相关衰落则需要**指定相关结构**的样本。

> [!info] Def 6 Cholesky 生成相关高斯
> 目标：$\mathbf{X}\sim N(\boldsymbol{\mu},\ \Sigma)$，其中协方差阵 $\Sigma$ **对称正定**。
> 1. 对 $\Sigma$ 做 **Cholesky 分解**：$\Sigma = LL^{T}$（$L$ 下三角）
> 2. 抽独立标准正态 $\mathbf{Z}\sim N(\mathbf{0}, I)$
> 3. 令
> $$
> \mathbf{X} = \boldsymbol{\mu} + L\,\mathbf{Z}
> $$
>
> **验证**：$E[(\mathbf{X}-\boldsymbol{\mu})(\mathbf{X}-\boldsymbol{\mu})^T] = E[L\mathbf{Z}\mathbf{Z}^T L^T] = L\,I\,L^T = \Sigma$ ✓

**二维显式形式**（$\sigma_1=\sigma_2=1$、相关系数 $\rho$）：

$$
L = \begin{bmatrix} 1 & 0 \\ \rho & \sqrt{1-\rho^2}\end{bmatrix} \;\Longrightarrow\; \begin{cases} x_1 = z_1 \\ x_2 = \rho\,z_1 + \sqrt{1-\rho^2}\,z_2\end{cases}
$$

> [!tip] 为什么是 $\sqrt{1-\rho^2}$
> 必须保证 $x_2$ 的**方差仍为 1**： $\mathrm{Var}(x_2) = \rho^2 + (1-\rho^2) = 1$ ✓
> 而 $\mathrm{Cov}(x_1,x_2)=\rho$ ✓ —— 这就是 Cholesky 因子的全部含义：**给独立分量"按配方掺入"相关性，同时不破坏各自的方差**。

## 3.6 其他方法与生成质量检验

| 方法 | 思路 | 场景 |
| --- | --- | --- |
| **复合/混合法** | 把 $f$ 拆成若干易抽样部分加权混合 | 分段定义的密度 |
| **卷积法** | $Z=\sum X_i$（如 Gamma = 若干指数之和） | 和的分布已知时 |
| **对数变换** | 对数正态 = $\exp(\text{正态})$，可直接用 | 阴影衰落建模 |
| **Box–Muller/Marsaglia** | 见 §3.4 | 正态及其派生 |
| **MCMC（Metropolis / Gibbs）** | 构造以目标分布为平稳分布的马尔可夫链 | 高维、只知道未归一化密度时 |
| **切片抽样** | 在密度曲线下均匀取点 | 一维通用，效率高 |

### 生成质量检验

| 检验 | 做法 | 判据 |
| --- | --- | --- |
| **KS 检验** | $D=\max\|F_n(x)-F(x)\|$ | $D < \dfrac{1.36}{\sqrt n}$（5% 显著性）→ 接受 |
| **卡方检验** | 分区间统计频数 | $\chi^2 < \chi^2_{0.05}(k-1)$ → 接受 |
| **Q–Q 图** | 经验分位数 vs 理论分位数作图 | 点落在 $y=x$ 直线上 → 拟合好 |
| **矩检验** | 比较样本均值/方差/偏度/峰度 | 大样本下应接近理论值 |

> [!note] 实机验证（KS 检验的判别力）
> - 对 `rand` 产生的均匀样本：$D=$ **0.00228** < 临界 0.00430 → **接受**均匀假设
> - 对 $U^2$（人为造出的偏斜样本）：$D=$ **0.2516** ≫ 临界 → **拒绝**均匀假设
> 说明 KS 检验确实能识别分布偏离，不是"永远接受"。
>
> **注意**：$n$ 很大时 KS 极其敏感（任何微小建模误差都会被检出），所以实践中常配合 Q–Q 图定性判断。

## 4.1 生成高斯白噪声

**模型**（[[vault-notes/communication/03-random-processes]]）：$n(t)$ 功率谱密度 $n_0/2$ 平坦、幅度服从高斯分布。**离散仿真**中：

$$
n_k = \sqrt{\frac{n_0}{2}}\,z_k, \qquad z_k \overset{iid}{\sim} N(0,1)
$$

即：**直接调用 `randn` 并按需缩放**。常用缩放关系：
- 指定噪声功率 $\sigma_n^2$：$n_k = \sigma_n z_k$
- 指定带通带宽 $B$ 与单边谱密度 $n_0$：$\sigma_n^2 = n_0 B$（见 [[vault-notes/communication/03-random-processes]]）

```matlab
sigma = 2;                        % 期望噪声标准差
n = sigma*randn(1,N);             % 高斯白噪声序列
```

**验证方法（三个角度）**：

```matlab
% (1) 时域：均值≈0、方差≈sigma^2
mean(n), var(n)
% (2) 相关域：白噪声自相关除 tau=0 外应≈0
nk = n - mean(n);
R = @(k) sum(nk(1:end-k).*nk(1+k:end))/(N-k);
R(1)/R(0), R(2)/R(0)              % 应接近 0
% (3) 频域：功率谱应平坦
X = fft(nk); P = abs(X).^2/N; P = P(1:floor(N/2));
% 分段平均后各段应近似相等
```

> [!note] 实机验证结论（$\sigma=2$，N=2×10⁵）
> - 时域：均值 **0.0026**（理论 0）、方差 **4.0127**（理论 4.0）✓
> - 相关域：归一化自相关 $R(1)=$ **0.0026**、$R(2)=$ **−0.0010**、$R(10)=$ **0.0019**（理论 0）✓
> - 频域：PSD 分 20 段后最大/最小 = **1.047**（越接近 1 越平坦）✓
> - **帕塞瓦尔校验**：频域总功率 4.013 ≈ 时域方差 4.013 ✓

> [!important] 白噪声"抽样不相关"的严格含义 ⭐（容易想当然）
> 上面验证的是**离散 i.i.d. 序列**。若要仿真**带限白噪声**（带宽 $B$），必须**先滤波**，此时教科书结论是
> $$
> R(\tau) = n_0 B\,\mathrm{Sa}(2\pi B\tau)
> $$
> 其零点在 $\tau = \dfrac{k}{2B}$ —— 即**每隔 $\dfrac{1}{2B}$ 取样才不相关**，间隔更密时样本是**强相关**的。
>
> **实机验证**（用 FFT 理想低通，$B=0.25$，归一化采样率 1）：
> - 隔 $1/(2B)=2$ 个样本取样 → 相关系数 **−0.0001**（理论 $\mathrm{Sa}(\pi)=0$）✓
> - 取**相邻**样本（间隔远小于 $1/(2B)$）→ 相关系数 **0.6367**（明显相关）✓
> - 带限后信号方差 **0.4990**（理论 $2B\sigma^2 = 0.5$）✓
>
> **这个对照正是抽样定理（[[vault-notes/communication/10-source-coding]]）的噪声版本**：只有按奈奎斯特间隔取样，样本才互不相关、不含冗余信息。

## 4.2 生成瑞利 / 莱斯衰落包络

**两条等价路线**：

| 路线 | 公式 | 特点 |
| --- | --- | --- |
| **① 求和法（物理法）** | $a=\sqrt{n_I^2+n_Q^2}$，$n_I,n_Q\sim N(0,\sigma^2)$ 独立 | 物理含义清晰（同相+正交分量），可自然扩展为莱斯 |
| **② 逆变换法（数学法）** | $a=\sigma\sqrt{-2\ln U}$ | 一行搞定，但无法加直射分量 |

**莱斯**（叠加直射分量 $A$）：

$$
r = \sqrt{(A+n_I)^2 + n_Q^2}, \qquad K = \frac{A^2}{2\sigma^2}
$$

$K$ 为莱斯因子（直射功率/散射功率）。$K=0$ 时退化为瑞利（见 [[vault-notes/math/probability/03-random-variables-distributions]]）。

## 4.3 蒙特卡洛估计误码率 ⭐⭐⭐

**为什么要蒙特卡洛**：[[vault-notes/communication/07-digital-bandpass]] 的误码率公式（如 $\frac12\mathrm{erfc}\sqrt r$）是在**理想条件下**推导的。实际系统有滤波器、同步误差、非线性 —— 此时只能靠仿真。

**标准流程（以 2PSK 相干解调为例）**：

```matlab
rng(2024); a = 1;                    % 载波幅度
for rdb = 0:10                        % 信噪比扫描
    r  = 10^(rdb/10);                 % 线性信噪比
    sg = a/sqrt(2*r);                 % 由 r=a^2/(2*sigma^2) 反解 sigma
    N  = 2e6;
    bits = 2*(rand(1,N)>0.5)-1;       % 等概双极性符号 +/-1
    rx   = bits*a + sg*randn(1,N);    % 加高斯噪声
    pe   = sum((rx.*bits) < 0)/N;     % 判决：与本地符号同号则正确
    pth  = 0.5*erfc(sqrt(r));         % 理论值
    fprintf('%4.0f dB  MC=%.3e  theory=%.3e\n', rdb, pe, pth);
end
```

> [!important] 蒙特卡洛的样本量限制 ⭐（仿真报告必写）
> 误码率估计的**相对标准差**：
> $$
> \frac{\sigma_{\hat P_e}}{P_e} \approx \frac{1}{\sqrt{N\,P_e}} \qquad (\text{小概率时})
> $$
>
> **95% 置信区间半宽**：$\;1.96\sqrt{\dfrac{P_e(1-P_e)}{N}}$
>
> | 目标 $P_e$ | N=10⁶ 时的相对半宽 | 要达 10% 精度所需 N |
> | --- | --- | --- |
> | 10⁻² | ~2% | 10⁴ |
> | 10⁻⁴ | ~20% | 10⁶ |
> | 10⁻⁶ | ~196% | 10⁸ |
>
> **结论**：要仿真 $P_e=10^{-6}$ 需要约 **10⁸** 个样本（Matlab 上约几十秒到几分钟）。直接仿真 $10^{-9}$ 量级（如 5G 要求）是不现实的 —— 这正是**重要抽样法**（importance sampling）、**半解析法**（semi-analytic）等技术存在的原因：把抽样集中到"会出错"的区域，或用解析式算条件误码率。

> [!tip] 三个仿真实践要点
> 1. **必须设 `rng`**：否则结果不可复现，也无法判断差异是算法问题还是随机波动。
> 2. **横轴用 $E_b/n_0$ 而不是 $r$**：$E_b/n_0$ 才是可跨调制方式比较的标尺（见 [[vault-notes/communication/09-optimal-reception]]）。对 2PSK 二者数值相同，但 2FSK/2ASK 需换算。
> 3. **画置信区间**：只报一条曲线没有说服力，应画出误差棒或标注样本数。


# 5. 例题

## 例 1（卷积公式：两个均匀分布之和）

设 $X,Y$ 独立同服从 $U(0,1)$，求 $Z=X+Y$ 的密度。

$f_X(x)=f_Y(x)=1\ (0<x<1)$。由卷积公式：

$$
f_Z(z) = \int_{-\infty}^{\infty} f_X(x)f_Y(z-x)\,\mathrm{d}x
$$

被积函数非零要求 $0<x<1$ **且** $0<z-x<1$，即 $x\in(\max(0,z-1),\ \min(1,z))$。区间长度即积分值：

$$
f_Z(z) = \begin{cases} z, & 0\le z<1 \\ 2-z, & 1\le z\le 2 \\ 0, & \text{其他}\end{cases}
$$

即**三角分布**（峰值 1 在 $z=1$）。

**实机验证**（N=3×10⁵）：均值 **1.0003**（理论 1.0）、方差 **0.1665**（理论 1/6≈0.1667）、**KS 统计量 0.00091** < 临界 0.00248 ✓

> [!tip] 推广
> $n$ 个独立均匀分布之和的密度是**分段多项式**（Irwin–Hall 分布），$n$ 增大时迅速趋近正态 —— 这是**中心极限定理**最直观的数值演示。实机验证：10 个均匀分布之和的偏度为 **0.0085**（单个均匀分布的偏度为 0）。

## 例 2（最大值/最小值的系统可靠性）

某系统由 5 个独立同分布元件组成，元件寿命 $T_i\sim E(\lambda)$（$\lambda=0.1$/年）。

**(1) 串联（全部工作才行）**：寿命 $T=\min T_i$。

$$
F_{min}(t) = 1-[1-F(t)]^5 = 1-e^{-5\lambda t}
$$

即**仍是参数为 $5\lambda$ 的指数分布**，平均寿命 $1/(5\lambda)=2$ 年 —— 只有单个元件的 1/5。

**(2) 并联（一个工作就行）**：寿命 $T=\max T_i$。

$$
F_{max}(t) = (1-e^{-\lambda t})^5, \qquad f_{max}(t) = 5\lambda e^{-\lambda t}(1-e^{-\lambda t})^4
$$

平均寿命 $=\frac{1}{\lambda}\left(1+\frac12+\frac13+\frac14+\frac15\right) = \frac{137}{60\lambda}\approx 22.8$ 年。

> [!important] 结论
> **冗余（并联）大幅延长寿命，串联则急剧缩短**；且并联的平均寿命虽大，但**方差也大**（"最差的那个"波动大）。这正是分集接收用多支路选最大的理论依据（§3.4）。

## 例 3（雅可比法推瑞利分布）

设 $X,Y$ 独立同分布 $N(0,\sigma^2)$，证明 $R=\sqrt{X^2+Y^2}$ 服从瑞利分布。

**解**：作极坐标变换 $x=r\cos\theta, y=r\sin\theta$（$r\ge0, 0\le\theta<2\pi$），反函数唯一，雅可比 $J=r$（推导见 §2.3）。联合密度

$$
f_{R\Theta}(r,\theta) = \frac{1}{2\pi\sigma^2}e^{-r^2/(2\sigma^2)}\cdot r
$$

对 $\theta$ 积分（$0$ 到 $2\pi$）：

$$
f_R(r) = \frac{r}{\sigma^2}e^{-r^2/(2\sigma^2)}, \qquad r\ge0 \quad\blacksquare
$$

**副产品**：$f_\Theta(\theta)=\frac{1}{2\pi}$（均匀分布），且 $f_{R\Theta}=f_R f_\Theta$ → **$R$ 与 $\Theta$ 独立**。

## 例 4（逆变换法生成瑞利）

用 $U(0,1)$ 生成参数 $\sigma=1.5$ 的瑞利随机数，并验证。

**解**：$F(x)=1-e^{-x^2/(2\sigma^2)}$，令 $u=F(x)$ 反解：

$$
x = \sigma\sqrt{-2\ln(1-u)}
$$

代码：`y = 1.5*sqrt(-2*log(1-rand(1,N)));`

**验证结果**（N=3×10⁵）：均值 1.8801（理论 $\sigma\sqrt{\pi/2}=1.8800$）、$E[X^2]=4.4979$（理论 $2\sigma^2=4.5$）、KS=0.00122 ✓

> [!warning] 注意 $\ln(1-U)$ 与 $\ln U$
> 因 $1-U$ 与 $U$ 同分布，两者结果分布相同。但**若程序里 $U$ 可能取到 0**，$\ln U$ 会溢出，此时用 $1-U$ 更安全（$U=1$ 才是问题，而 `rand` 返回 $[0,1)$ 闭开区间，取不到 1）。

## 例 5（舍选法生成三角分布）

用舍选法生成 例 1 的三角分布 $f(x)=x\ (0\le x\le1)$，$2-x\ (1<x\le2)$。

**解**：取包络 $g(x)=U(0,2)$（密度 $1/2$），$\max f = 1$，故 $M = 1/(1/2) = 2$。

算法：抽 $Y\sim U(0,2)$、$U\sim U(0,1)$；若 $U \le f(Y)/2$ 则接受。

**接受率** = $\dfrac{\int_0^2 f\,\mathrm{d}x}{M\cdot 2} = \dfrac{1}{2\times2}=\dfrac{1}{4}$。

**实机验证**（N=2×10⁵）：均值 1.0004、方差 0.1668、**接受率 0.2443**（理论 0.25）、KS=0.00136 ✓

## 例 6（Box–Muller 两分量的独立性验证）

生成 $Z_1,Z_2$ 各 4×10⁵ 个，验证它们独立且都是标准正态。

**解与验证**：计算

- 均值：0.0024 / 0.0030（理论 0）
- 标准差：1.0016 / 1.0010（理论 1）
- **相关系数：0.00104**（理论 0）→ 不相关
- 峰度：3.0112（理论 3）

由于 $(Z_1,Z_2)$ 是**二维高斯**（高斯经线性变换仍为高斯），**不相关即独立** → 独立性成立 ✓

> [!tip] 关键逻辑
> "不相关"一般推不出"独立"，但**高斯情形下可以**（§2.3）。所以这里只需验证相关系数≈0 即可断言独立 —— 这正是高斯分布在仿真中特别方便的原因之一。

## 例 7（Cholesky 生成 $\rho=0.8$ 的相关高斯）

生成样本量 $3\times10^5$、协方差阵 $\Sigma=\begin{bmatrix}1&0.8\\0.8&1\end{bmatrix}$ 的二维高斯，并验证。

**解**：

$$
L = \mathrm{chol}(\Sigma) = \begin{bmatrix}1 & 0\\ 0.8 & 0.6\end{bmatrix} \;\Longrightarrow\; \begin{cases} x_1 = z_1\\ x_2 = 0.8z_1 + 0.6z_2\end{cases}
$$

**验证结果**：样本协方差 $S_{11}=1.0002$、$S_{22}=0.9989$、$S_{12}=0.8000$；样本相关系数 **0.8004** ✓

**三变量**（等相关 $\rho=0.5$）：非对角均值 **0.5027** ✓

## 例 8（蒙特卡洛误码率与理论对比）

对 2PSK 相干解调，用 $N=2\times10^6$ 个样本估计 $r=6$ dB 时的误码率，并与理论值比较；若要达到 10% 的相对精度，需要多少样本？

**解**：$r=6$ dB → $r=3.981$，理论

$$
P_e = \frac12\mathrm{erfc}(\sqrt{3.981}) = 2.388\times10^{-3}
$$

仿真得 **2.366×10⁻³**，相对误差 0.9% ✓

**样本量估计**：要求相对标准差 $\dfrac{1}{\sqrt{NP_e}}\le10\%$：

$$
N \ge \frac{1}{P_e\,(0.1)^2} = \frac{1}{2.388\times10^{-3}\times0.01} \approx 4.2\times10^4
$$

即约 **4 万个样本**即可。但若目标是 $P_e=10^{-6}$，则需 $N\ge10^8$ —— 这就是高信噪比区仿真困难的定量原因。

```matlab
% 指数分布 E(lambda), lambda = 2
u = rand(1,N);  x = -log(1-u)/2;
% 瑞利分布 R(sigma), sigma = 1.5
```

## 6.2 舍选法：三角分布

```matlab
rng(7); N = 1e5;
f = @(x) (x<=1).*x + (x>1).*(2-x);      % 目标密度
M = 2; out = zeros(1,N); k = 0;
while k < N
    xs = 2*rand(1,N); ys = M*rand(1,N);
    acc = xs(ys <= f(xs));               % 落在曲线下的接受
    t = min(numel(acc), N-k);
    out(k+1:k+t) = acc(1:t); k = k + t;
end
```

## 6.3 Box–Muller 与 Marsaglia

```matlab
rng(11); N = 1e5;
% Box-Muller：两个均匀数 -> 两个独立正态
u1 = rand(1,N); u2 = rand(1,N);
z1 = sqrt(-2*log(u1)).*cos(2*pi*u2);
z2 = sqrt(-2*log(u1)).*sin(2*pi*u2);

% Marsaglia 极坐标法（免三角函数，更快）
out = zeros(1,N); k = 0;
while k < N
    v = 2*rand(2,N)-1;  s = sum(v.^2);
    ok = (s>0)&(s<1);
    f = sqrt(-2*log(s(ok))./s(ok));
    c = [v(1,ok).*f; v(2,ok).*f];
    t = min(N-k, size(c,2));
    out(k+1:k+t) = c(1,1:t); k = k + t;
end
```

## 6.6 瑞利 / 莱斯衰落

```matlab
rng(9); N = 3e5; sigma = 1;
zI = sigma*randn(1,N); zQ = sigma*randn(1,N);
% 瑞利（无直射）
ray = sqrt(zI.^2 + zQ.^2);
% 莱斯（直射幅度 A）
A = 2;  rice = sqrt((A+zI).^2 + zQ.^2);
fprintf('瑞利均值=%.4f (理论 %.4f)\n', mean(ray), sigma*sqrt(pi/2));
% 与理论密度对比
v = 0:0.05:5; fth = v/sigma^2.*exp(-v.^2/(2*sigma^2));

```

## 6.7 蒙特卡洛误码率

```matlab
rng(2024); a = 1;
for rdb = 0:2:10
    r = 10^(rdb/10); sg = a/sqrt(2*r); N = 2e6;
    bits = 2*(rand(1,N)>0.5)-1;
    rx = bits*a + sg*randn(1,N);
    pe = sum((rx.*bits) < 0)/N;
    pth = 0.5*erfc(sqrt(r));
    hw = 1.96*sqrt(pe*(1-pe)/N);        % 95% 置信半宽
    fprintf('%2.0f dB  MC=%.3e +-%.1e  th=%.3e\n', rdb, pe, hw, pth);
end
```

> [!tip] 附录收官
> 本附录用"两条互逆主线"把第 3–4 章留下的空白补齐：
> 1. **正向（求分布）**：已知 $X$（或 $(X,Y)$）的分布，求 $Y=g(X)$、$Z=g(X,Y)$ 的分布——分布函数法、卷积、雅可比、顺序统计量。
> 2. **反向（造样本）**：已知目标分布，用均匀随机数生成样本——逆变换、舍选、Box–Muller、Cholesky。
> 3. **汇合（通信仿真）**：高斯白噪声、瑞利/莱斯衰落、蒙特卡洛误码率。
>
> 一句话：**求分布是"由因到果"，生成是"由果造因"；两者在通信仿真里闭环——用生成算法造数据，用分布理论验证数据。**

# 本章知识地图

```
随机变量函数（正向：求分布）
   │
   ├─ 一维  Y = g(X)
   │    ├─ 分布函数法（万用）
   │    ├─ 单调公式 f_Y = f_X(h(y))|h'(y)|
   │    └─ 非单调：分段求和（如 Y=X² → χ²(1)）
   │
   ├─ 二维  Z = g(X,Y)
   │    ├─ 分布函数法（画区域）
   │    ├─ 和 → 卷积公式 f_X * f_Y
   │    ├─ 差/积/商 → 各自的积分公式
   │    └─ 雅可比行列式法（多维变换）→ 瑞利分布的几何来源
   │
   └─ 顺序统计量
        ├─ max：F^n        （并联系统 / 选择式分集）
        └─ min：1-(1-F)^n  （串联系统）

随机变量生成（反向：造样本）
   │
   ├─ 源头：均匀随机数
   │    └─ LCG  x_{n+1} = (a x_n + c) mod m
   │
   ├─ 逆变换法  X = F⁻¹(U)          ← 指数/瑞利/威布尔/离散
   ├─ 舍选法    包络 M·g(x) ≥ f(x)   ← 复杂密度；接受率 = 面积比
   ├─ Box–Muller / Marsaglia         ← 正态（两个均匀→两个独立正态）
   ├─ Cholesky  X = μ + L·Z          ← 相关高斯 Σ = LLᵀ
   └─ 其他：复合/卷积/MCMC/切片
   │
   └─ 质量检验：KS 检验 / 卡方 / Q–Q 图 / 矩检验

通信仿真（两者的汇合处）
   ├─ 高斯白噪声       n = σ·randn     ← 逆变换/内置
   ├─ 瑞利衰落         √(nI²+nQ²)      ← 求和法（雅可比法的反用）
   ├─ 莱斯衰落         √((A+nI)²+nQ²)  ← 加直射分量
   └─ 蒙特卡洛误码率   N ≥ 1/(P_e·ε²)  ← 样本量是核心约束
```
